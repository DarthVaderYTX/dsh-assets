# 选型与反模式

先确定**图要回答的问题**，再选图型。图型选错的代价比配色难看大得多：读者会得出错误结论，而且很难察觉。

## 1. 按问题选

| 问题 | 首选 | 次选 | 不要用 |
| --- | --- | --- | --- |
| 随时间变化的趋势 | 折线 | 面积（强调累计量） | 饼图、柱状（时间点很多时） |
| 分类之间比大小 | 柱状 | 排名柱状 + 数值标签 | 饼图、折线 |
| 总量由哪些部分构成 | 堆叠柱 | 100% 堆叠柱 | 双轴、面积叠加 |
| 单一时点的占比（≤6 类） | 环形图 | 堆叠单柱 | 3D 饼图 |
| 两个指标的关系 | 散点 | 气泡（第三维） | 双轴折线 |
| 两个维度的强度 | 热力图 | 分组柱 | 折线 |
| 从期初到期末的拆解 | 瀑布 | 分组柱 + 差值 | 饼图 |
| 排名前 N | 柱状 + `sort: desc` | 表格 | 横向条形图（本版未做） |
| 精确数值、多列对比、要查明细 | 交互表格 | 附 CSV | 把表格硬画成图 |

## 2. 什么时候用表格而不是图

图的优势是**形状**，表格的优势是**精确**。出现下面任意一条，优先表格（或图 + 表并存）：

- 读者需要抄下或核对具体数字（金额、编号、比率）。
- 一行有 4 个以上属性要同时对比。
- 需要按某列排序、按关键词筛出子集。
- 数据点太多（> 40 行），图会糊成一团。
- 每行是独立对象（城市、门店、SKU），而不是同一指标的连续序列。

表格的代价是「看不出趋势」，所以趋势类问题仍应配一张图。

## 3. 硬规则

**柱状图必须从 0 起。** 截断基线会把 5% 的差异画成 3 倍。`y.min > 0` 对柱/面积是错误（`--check` 会拦），折线才可以截断。

**占比只在总和有意义时用饼/环。** 各分类互不重叠、加起来是整体，才叫占比。增长贡献、转化漏斗、排名都不适合。

**双轴只在两个量纲都不可换算时用。** 用了就必须两侧都写标题和单位；否则读者会把两条线当同一量纲比较。

**时间轴用 `type: time`。** 不等距采样（每月天数不同、发布日不规则）用分类轴假装等距会歪曲斜率。

**类别多于 12 个时先聚合。** 40 个分类的柱状图没有可读性；按 Top-N + 其他、或按时间聚合。

**表格的条件格式必须围绕 0。** 有正有负的列不能用 min–max 铺满色阶，否则 +3% 会被染成「差」的颜色。

## 4. 反模式

| 反模式 | 为什么不行 | 改成 |
| --- | --- | --- |
| 3D 柱/饼、阴影、渐变背景 | 视觉噪声，读取误差 | 平面、单色系 |
| 彩虹色板 | 颜色本身变成信息，但无意义 | 固定分类色板 |
| 每根柱子一个颜色 | 分不清哪些属于同一维度 | 同维度同色 |
| 饼图 12 个切片 | 小切片无法比较 | 环形 + 前 5 类 + 其他 |
| 折线连空值 | 伪造了不存在的趋势 | 数据里写 `null`，线会断开 |
| 双轴 + 不同时间范围 | 两条线的交叉毫无意义 | 统一口径重画 |
| 只放截图 | 读者无法核对数值 | 交互版给数据表，静态图写图注与来源 |
| 图标题写「趋势图」 | 没传达结论 | 写「检索延迟 8 月起上升 20%」这类判断 |
| 表格塞 20 列 | 横向滚动，读者只看到前几列 | 拆表或列分组 |

## 5. 数量与密度

| 维度 | 建议上限 | 超过时 |
| --- | --- | --- |
| 折线系列 | 4–5 | 合并小类；或拆成小倍数 |
| 柱状系列（分组） | 3–4 | 改成堆叠或拆图 |
| 分类数（柱状） | 12 | 聚合或排序取 Top N |
| 分类数（折线） | 30 | 时间轴 + 抽稀，或按月聚合 |
| 饼/环切片 | 6 | 前 5 类 + 其他 |
| 热力图单元格 | 12×12 | 合并分箱 |
| 表格行数 | 一屏 8–12 行 | 分页（`page_size`）或筛选 |
| 表格列数 | 6–8 列 | 拆表、合并列、把明细放 CSV |

## 6. 排序与基线

- **排名**：`sort: desc`，数值标签打开，分类按排名顺序；不要保留原始顺序让读者自己找。
- **时间序列**：永远按时间升序，不要按值排序。
- **分组柱**：组内顺序在所有分类上保持一致，颜色与图例顺序一致。
- **堆叠柱**：把最稳定、最大的部分放底部；正负分量分开堆叠（`--check` 会警告混用）。
- **表格**：默认按业务含义排序（如收入降序），并让表头排序可用；不要给读者一个随机顺序。

## 7. 配色与语义

- 同一系列在所有图里用同一个色位（默认按系列顺序取色板）。
- 强调一个系列用图例隐藏其他系列，或加数值标签；不要换一套颜色。
- 涨跌语义（瀑布、表格条件格式）用固定语义色：正向蓝、负向红、合计深灰；不要用分类色板。
- 语义色不要同时承担分类：一张图里「红」只表示一种含义。
