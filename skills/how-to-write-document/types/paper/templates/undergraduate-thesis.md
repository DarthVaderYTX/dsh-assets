# 本科毕业论文（学位论文）：内部写作模板

适用：中文撰写的本科毕业论文（设计），以及需要按院系模板提交的学位论文初稿。以北京大学经济学院、清华大学两个校级口径作为对照示例；不是任何学校的官方模板。
学位论文与期刊论文是两种交付物：前者受学校模板、字数、查重、答辩与声明约束，后者受刊物指南约束。不能把期刊的字数、摘要限长、引用格式直接套到学位论文上，反之亦然。
本文件只提供内容骨架与院校要求对照。正式提交以**当届通知 + 入学年级培养方案 + 学校官方模板**为准，三者冲突时以最新通知与院系答复为准。
未核实的个人信息、成绩、评阅意见、查重结果不得代填；示例数值一律虚构。
编号 0~11 与[论文写作规范](../README.md)第三部分的十二个模块一一对应，章节名按学位论文惯例做了调整（如"引言（绪论）""结论与展望""学术规范声明与致谢"），语义不变。

## 一、空白模板

```markdown
## 0. 封面与论文信息
[论文题目：中文题目按学校要求控制字数（如清华本科≤25 个汉字）；副标题按需]
[作者、学院、专业、班级、学号、指导教师、完成日期：逐项核实，未定留占位]
[学校要求的封面字段、密级、中图分类号等：按当届模板；不自行增删]

## 1. 摘要与关键词
[中文摘要：研究问题、方法、主要结果与结论；不写文献综述，不列图表编号]
[关键词 3~5 个，分号分隔；与正文术语一致，不使用正文未出现的概念]
[Abstract 与中文摘要对应，不做逐字机翻；关键词同样 3~5 个]
[摘要字数按学校规定；学校未规定时以能独立说明问题、方法、结果、结论为准，不套用期刊 300 词限制]

## 2. 引言（绪论）
[研究背景与现实问题；为何值得研究；研究范围界定]
[国内外研究现状：按主题归纳，指出研究缺口；本科层次以评述为主，不做穷尽罗列]
[研究内容、方法与技术路线；论文结构安排]

## 3. 文献综述与理论基础
[与选题直接相关的代表性文献、主要观点与分歧]
[所依据的理论、模型或技术原理；概念界定与假设]
[已有研究的不足与本文的切入点；标注引用，不复制他人表述]

## 4. 研究方法与设计
[研究设计或系统设计：对象、数据来源、变量或模块划分、实施步骤]
[数据采集与处理：样本、时间范围、清洗规则、缺失与异常处理；访谈需说明对象与提纲]
[实验或实现环境、工具版本、参数设置、评价指标]
[适用时说明信度效度、统计方法或系统测试方案；方法局限在讨论中呼应]

## 5. 结果与分析
[按研究问题组织结果：主结果、对照、关键数据，配图表]
[每项结果说明口径、单位、样本量与来源；区分观察、计算与解释]
[实证类给出回归/检验结果与稳健性；系统类给出功能测试与性能测试结果]
[保留负面结果、异常样本与未达预期的部分，并说明可能原因]

## 6. 讨论
[结果的含义：回答研究问题，与文献比较异同]
[原因分析、机制解释或设计权衡；区分已验证结论与推测]
[研究局限：数据、样本、方法、外部有效性；对结论适用范围的影响]
[对实践或后续研究的启示；不引入正文未出现的新结果]

## 7. 结论与展望
[明确回答研究问题；概括主要工作与得到证据支持的结论]
[创新点或贡献表述克制，与正文证据对应；不夸大应用价值]
[不足与后续工作；不把未完成工作写成已完成]

## 8. 数据、代码与材料说明
[数据、程序、问卷、访谈记录、原始材料的存放与获取方式]
[受保密、隐私或版权限制的部分：说明限制与可提供的范围]
[学校未要求本章节时，可并入附录或方法章节，不虚设章节]

## 9. 学术规范声明与致谢
[原创性声明、使用授权说明按学校模板签署；不代签、不预填日期]
[致谢对象与措辞：真实、具体、不虚构合作与资助]
[AI 工具使用情况按学校规定披露；作者对全文负责]
[指导教师评语、成绩评定表等由教师填写，学生不代填]

## 10. 参考文献
[仅列正文实际引用且已阅读的文献；格式按学校模板，不混用两套体例]
[作者-年份制（如北大经院本科）：中文在前、英文在后，各按姓氏音序排列]
[顺序编码制：按正文首次引用顺序编号，正文标注与文末条目双向对应]
[核对作者、年份、题名、出处、页码或 DOI；不编造文献，不引用未读文献充数]

## 11. 附录
[问卷、访谈提纲、核心代码、完整表格、推导过程、系统截图等]
[编号与正文引用一致；附录不替代正文的必要论证]
```

## 二、填写示例

以下片段完全虚构，仅演示模块 0、1、2、4、5、7、9 的写法与粒度，不对应任何真实论文、真实学校要求或真实数据。

```markdown
题目（模块0）：基于订单数据的社区团购自提点选址优化研究（虚构题目）
作者信息：学院、专业、学号、指导教师均为占位；完成日期待定。
摘要（模块1）：针对自提点覆盖率低导致的履约成本上升问题，以某市 6 个月订单为样本，
比较三种选址方案的覆盖半径与配送成本；结果显示在同等点位数下成本下降幅度有限，
并受订单密度分布影响。（虚构示例，数值未给出，不得直接引用）
关键词（模块1）：社区团购；选址优化；覆盖模型；履约成本
研究缺口（模块2）：已有研究多基于需求均匀假设，缺少对订单密度不均的讨论。
数据与方法（模块4）：订单数据脱敏后按网格聚合；以覆盖模型与贪心算法生成候选方案；
样本期、网格粒度与参数待实验确定，不预设结论。
结果写法（模块5）：分别报告覆盖人口比例、平均配送距离与单均成本；三者的口径与分母须一致，
未完成计算前只保留占位，不填估算值。
结论（模块7）：仅陈述被数据支持的判断，例如"在订单密度低于阈值的区域，增加点位的边际收益下降"；
不写"具有重大推广价值"。
声明与致谢（模块9）：原创性声明按学校模板签署；致谢只写真实给予帮助的人；
不虚构企业数据授权与基金资助。
```

### 院校硬性要求对照（经济学科示例，本科为主）

| 项目 | 北京大学经济学院（2026 届本科） | 清华大学（校级，本科"综合论文训练"） |
|---|---|---|
| 字数 | 10000 字左右 | 校级不设下限，由院系/专业规定 |
| 结构顺序 | 封面 → 版权声明 → 中文摘要 → ABSTRACT → 目录 → 正文 → 参考文献 → 附录 → 致谢 → 原创性声明 | 封面 → 使用授权说明 → 摘要 → Abstract → 目录 → 图表清单 → 符号说明 → 正文 → 参考文献 → 附录 → 致谢 → 声明 → 研究成果 → 记录表；每部分另起一页 |
| 题目 | 黑体一号加粗居中 | ≤25 个汉字（符） |
| 正文字体行距 | 宋体小四、首行缩进 2 字符、1.5 倍行距 | 宋体小四、固定行距 20 磅、首行缩进 2 字符 |
| 标题层级 | 一级"一、二、三"黑体四号加粗；二级"（一）（二）"宋体小四缩进 1 字符；三级"1、2、3"宋体小四缩进 3 字符 | 章标题黑体三号居中；一级节黑体四号；二级节黑体 13pt |
| 摘要与关键词 | 摘要标题黑体三号；关键词 3~5 个，分号分隔 | 摘要单设一页；关键词 3~5 个 |
| 图表题注 | 按院系模板 | 图题在下、表题在上，宋体五号 |
| 参考文献 | 作者-年份制；中文在前英文在后，各按姓氏音序；只列正文引用过的 | 宋体五号，悬挂缩进 |
| 过程管理 | 开题 → 中期 → 两次查重 → 全员答辩 → 终稿 PDF → 纸质提交，日期固定 | 执行≥18 周；第七学期末前开题；第八学期第 16 周前答辩；中期建议完成≥50%；查重答辩前完成，另有校级抽检 |
| 答辩组织 | 各专业组织，全员参加 | 校内答辩，小组≥3 人，本校教师≥2/3 |
| 其他 | 纸质双面打印，第二页附成绩评定表（导师签字） | 成绩等级制 |

研究生层次的方向性差异（不作为本科要求，避免误用）：北大经院自 2014 级起不再招收全日制学术型硕士，其硕士论文口径为专业学位；北大研究生格式总纲仍为 2007 年修订版，题目一般不超过 20 字、中文摘要 3000 字以内；清华研究生写作指南（2023 年 3 月印）要求题目≤25 汉字、中文摘要 800~1000 字且限一页。评阅与答辩人数、匿名方式、发表要求等按当年文件核对，不在本表内固化。

### 提交映射说明

- 模块 0 → 封面与版权/授权页；学校模板已含固定字段时直接填写，不增删字段。
- 模块 1 → 中文摘要与 ABSTRACT（清华另需图表清单与符号说明时，按模板单独成页）。
- 模块 2、3 → 正文第 1 章引言与文献综述/理论基础；本科可合并，但研究缺口与文献支撑不能省。
- 模块 4、5、6 → 研究设计、结果与分析、讨论；章节名与顺序按学校模板与学科惯例调整。
- 模块 7 → 结论（清华"综合论文训练"通常以"结论"章收尾，不写展望时可保留精简版）。
- 模块 8 → 附录或方法章节内的数据说明；学校无此要求时不虚设章节。
- 模块 9 → 原创性声明、使用授权说明、致谢、成果清单；评语与成绩表由教师填写。
- 模块 10、11 → 参考文献与附录；引用体例必须与学校模板一致，不混用两套体例。

### 提交前的流程性检查

- [ ] 当届模板、院系补充规定与培养方案已下载并核对版本年份。
- [ ] 字数、章节顺序、字体字号、行距、层级编号、题注位置与模板逐项一致。
- [ ] 参考文献体例统一，正文标注与文末条目双向对应，无未引用条目。
- [ ] 原创性声明、使用授权、AI 使用披露按学校要求签署，日期与签名真实。
- [ ] 查重版本与答辩版本、终稿版本一致，修改留痕；未把查重结果写成"已通过"除非确有结论。
- [ ] 提交格式（PDF/Word）、文件名规则、双面打印与纸质份数符合通知要求。
