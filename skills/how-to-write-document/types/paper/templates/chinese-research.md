# 中文研究论文：内部写作模板

适用：以《软件学报》为参照的中文原创研究论文；不是期刊官方排版模板。
十二个编号模块用于内部写作与检查，不代表期刊要求采用这些标题。
正式投稿须下载并核对当时的官方 Word 模板，允许按官方顺序重排、合并模块。
未核实的作者、数据、DOI、基金等保留占位，不凭空补全，不复制真实论文正文。

## 一、空白模板

```markdown
## 0. 标题、作者与稿件信息
[中文标题：对象、方法与问题；英文题名按官方模板填写]
[作者姓名、单位、通讯作者、联系方式：待确认；稿件版本与日期]
[投稿类型、目标期刊、原创性与相关稿件情况：待确认]

## 1. 摘要与关键词
[问题背景与目标；提出的方法；经核验的主要结果；贡献与边界]
[中文关键词：待填；英文摘要与关键词按官方模板填写]
[摘要中的量化结果须能回指结果证据，未完成实验不得写成已验证]

## 2. 引言与研究问题
[应用或理论背景；现有方案不足；为什么值得研究]
[明确研究问题或假设；本文范围；核心贡献概述]

## 3. 相关工作与贡献定位
[国内外相关工作分类；真实来源占位：作者、题名、年份、DOI待核]
[比较问题、假设、方法、数据与适用条件，不只罗列文献]
[明确他人工作与本人贡献；比较表中的结论逐项给出来源]

## 4. 研究方法与可复现信息
[问题形式化、符号、输入输出、关键算法与理论假设]
[数据来源、许可、筛选、划分与泄漏防范；数据规模待核]
[实现、版本、环境、参数、随机性、基线、指标与复现步骤]
[适用时说明统计分析与不确定性；非统计研究说明证明或验证路径]

## 5. 结果与证据
[按研究问题组织结果；指标、对照、消融与失败案例]
[每项主张对应图表、实验记录或证明；数值与误差范围待核]
[图序、图题、图注；图内文字、单位、样本含义与来源清楚]
[区分观察结果与推断，保留负面结果和异常解释]

## 6. 讨论、局限与适用边界
[结果为何产生；与国内外同类工作的异同及可能原因]
[内部、外部、构念与结论有效性威胁；适用条件与不适用场景]
[无法由现有证据回答的问题；未来验证路径]

## 7. 结论
[回答研究问题；概括已被证据支持的贡献]
[不引入新数据，不把限定场景的结果扩大为普遍结论]

## 8. 数据、代码与材料可用性
[数据、代码、材料仓库或持久链接：待填；版本、许可与访问条件]
[不能公开时说明具体限制、可提供部分与申请方式；勿虚构已开源]

## 9. 伦理、作者贡献、利益冲突与资助
[伦理审批、知情同意、隐私与安全处理：适用性及真实状态待核]
[各作者贡献、利益冲突、资助机构与编号：逐项确认]
[致谢与署名授权；内容按期刊模板或投稿系统安排]

## 10. 参考文献
[仅列实际查阅和文中引用的来源；作者、年份、题名、出版信息、DOI待核]
[依当前官方模板整理标引与格式，正文和文后条目双向核对]

## 11. 附录与补充材料
[证明、伪代码、参数表、额外实验、数据字典与复现说明]
[清单、版本、正文引用位置、公开范围与脱敏状态]
```

## 二、填写示例

以下是明确虚构的短片段，仅演示模块 0、2、4、5、6、8 的写法；无真实实验数据。
其余模块仍按空白模板填写；本例不提供虚构引文编号、作者或 DOI。

```markdown
题名（模块0）：依赖约束引导的头文件拆分候选生成方法（虚构题名）
作者、单位与DOI：待确认；本片段不对应已发表论文。
研究问题（模块2）：如何生成可审查的拆分候选，并标出可能破坏依赖的边界？
方法（模块4）：将符号引用表示为有向图，依据依赖约束筛选拆分候选。
评估计划（模块4）：在许可明确的项目上与待核实基线比较；项目与参数尚未确定。
结果写法（模块5）：候选有效性、编译影响和人工审查成本分别报告；数值待实验。
讨论（模块6）：宏展开与条件编译可能使静态依赖图不完整，暂不主张跨项目泛化。
可用性（模块8）：代码与项目清单尚未发布；仓库地址、版本和许可待确认。
```

## 三、真实示例与官方依据

- [《软件学报》投稿指南](https://www.jos.org.cn/jos/site/menu/20210909102616001)：依据包括原创性、充分的国内外相关比较、图序图题图注，以及 Word 编辑排版和网站写作模板。
- [面向复杂头文件的自动化分解与重构方法](https://www.jos.org.cn/jos/article/abstract/7556)：官网论文页；用于观察真实题名、摘要及方法与证据组织，不把其结果移植到本例。
- 真实论文的作者、数据与 DOI 如需用于参考文献，应进入论文页逐项核验；本文件未替未知信息补值。
- 官方页面含不同年代的 FAQ；涉及旧格式、旧软件版本或相互冲突的规定，不硬编码为当前要求，以当前模板、投稿系统及编辑部确认为准。

### 投稿映射说明

- 模块 0、1 → 官方模板中的题名、署名、单位、中英文摘要与关键词等前置信息。
- 模块 2、3 → 引言与相关工作；可合并，但不得删掉国内外比较与贡献辨析。
- 模块 4、5、6、7 → 方法、实验或证明、讨论、结论；章节名与顺序按文章和官方模板调整。
- 模块 8、9 → 可用性声明、伦理与贡献、利益冲突、基金及致谢等相应位置或系统字段；不假定全部必须独立成节。
- 模块 10、11 → 参考文献、附录或补充材料；是否纳入正文及版式以当次投稿要求为准。
- 本文只提供内容骨架；正式投稿还须核查图表、公式、参考文献、署名和声明的官方格式。
