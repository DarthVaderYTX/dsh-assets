# 综述论文：内部写作模板

十二个编号模块用于内部写作与映射，不是任何期刊的官方排版模板。
正式投稿允许按目标刊物的官方顺序重排或合并；研究类型须先确定，不能靠文献罗列冒充系统综述。
叙述综述：围绕主题解释、比较与批判性综合，须说明选材逻辑及选择性局限。
范围综述：描绘概念、证据类型与研究分布，交代检索、筛选和资料提取；可按适用性参考 PRISMA-ScR。
系统综述：用明确问题和可复现检索筛选方法综合证据，按适用要求报告质量评价与偏倚；不必必然做元分析。
PRISMA 是报告指南而非认证；只有实际执行且逐项核对后，才能描述采用情况，不能将计划写成已完成。

## 一、空白模板

```markdown
## 0. 标题、作者与稿件信息
[题名与综述类型：叙述 / 范围 / 系统；若有元分析须明确]
[作者、单位、通讯方式、版本、目标刊物：待确认]
[方案、注册平台、编号、DOI与偏离记录：实际状态待核，未注册如实写]

## 1. 摘要与关键词
[问题、综述类型、来源与选材方法、主要综合发现及边界]
[关键词待填；PLOS ONE 英文摘要≤300 words且无引文]
[检索截止时间、纳入数量与结果未知时保留占位，勿编造流程数字]

## 2. 引言与研究问题
[为什么需要综述；领域争议或证据缺口；读者与使用场景]
[研究问题与范围；按适用性界定人群、概念、情境或其他问题框架]

## 3. 相关工作与贡献定位
[已有综述的覆盖范围、时效、方法与局限；真实来源信息待核]
[本综述新增的分类、证据综合或视角；避免无依据声称“首个”]

## 4. 研究方法与可复现信息
[叙述：选材来源、选择理由与覆盖边界，勿声称穷尽检索]
[范围/系统：数据库与平台、逐库完整检索式、检索日期与语言/时间范围]
[纳入排除标准、去重、筛选人员及分歧处理、提取表与编码规则]
[质量/偏倚评价：依综述目的说明适用性、工具、过程或未做理由]
[综合方法：主题、框架或定量；元分析仅在可合并且方法适当时使用]
[方案、注册与偏离实际状态；报告清单的适用性及未覆盖项]

## 5. 结果与证据
[范围/系统：筛选流程及真实排除理由；数量与记录须一致]
[文献特征表、分类框架、证据矩阵；每项结论回指已核实来源]
[区分文献所报告的发现与综述作者推断；保留矛盾与证据空白]
[适用时报告质量/偏倚评价、效应与不确定性、异质性和敏感性分析]
[叙述综述报告主题综合及选材边界，不伪造 PRISMA 流程]

## 6. 讨论、局限与适用边界
[回答研究问题；解释一致与冲突结果，比较已有综述]
[来源、语言、时间范围、检索遗漏、编码主观性和原研究偏倚]
[证据缺失不等于效果不存在；区分研究建议与实践建议的证据强度]

## 7. 结论
[概括综合结论与未解决问题；不将有限证据扩大为普遍规律]
[若证据不足，明确哪些判断仍不能作出]

## 8. 数据、代码与材料可用性
[检索记录、筛选决定、提取表、编码字典、分析代码与版本]
[仓库、许可、持久标识或DOI待核；说明受版权限制的全文不公开]

## 9. 伦理、作者贡献、利益冲突与资助
[伦理适用性、个人或非公开数据处理；作者贡献与利益冲突待核]
[资助与致谢待确认；PLOS ONE 资助仅填系统financial disclosure，不入稿件]

## 10. 参考文献
[仅列真实且可追溯来源；作者、出版信息与DOI未知时保留占位]
[核查撤稿/更正及引用准确性；PLOS ONE 用Vancouver顺序编号]

## 11. 附录与补充材料
[适用的完整检索式、排除记录、提取表、评价工具与报告清单]
[流程图和补充表须来自实际记录；条目、版本和正文引用对应]
```

## 二、填写示例

以下为完全虚构的**叙述综述**片段，无真实数据，覆盖模块 0、2、3、4、5、6、8。
其他模块按模板填写；不提供虚构作者、DOI、引文数字或筛选数量。

```markdown
题名（模块0）：检索增强代码问答的证据组织：叙述综述（虚构题名）
问题（模块2）：现有讨论如何区分检索来源质量与生成答案可验证性？
定位（模块3）：拟从“来源—检索—回答—验证”链条组织比较；既有综述待核。
选材（模块4）：计划围绕可追溯来源选择主题相关文献；尚未执行检索或筛选。
综合写法（模块5）：比较表将记录任务、来源与验证方式；真实条目尚待提取。
边界（模块6）：不能据选材计划声称全面覆盖，也不能据文献数量判定方法有效。
材料（模块8）：提取表尚未生成；仓库、许可与DOI待确认。
```

## 三、真实示例与官方依据

- [检索增强生成在软件工程中的应用综述](https://www.jos.org.cn/jos/article/abstract/7567)：《软件学报》官网确认的综述题名；用于观察真实综述的主题与组织，不仅凭题名判定其为系统综述，也不移植其结论。
- [《软件学报》投稿指南](https://www.jos.org.cn/jos/site/menu/20210909102616001)：中文投稿的内容、国内外比较与官方 Word 模板依据；旧 FAQ 冲突或旧版本规定不硬编码。
- [PLOS ONE：Systematic reviews and meta-analyses](https://journals.plos.org/plosone/s/submission-guidelines#loc-systematic-reviews-and-meta-analyses)：系统综述/元分析的具体报告要求；投稿前核查清单、流程图和方案等适用要求，不能只把叙述综述改名。
- [PRISMA 2020 官方入口](https://www.prisma-statement.org/prisma-2020)：系统综述报告指南；按研究问题与适用扩展逐项核对，不表示认证或本模板已执行。
- [PRISMA-ScR 官方入口](https://www.prisma-statement.org/scoping)：范围综述报告扩展；不是所有叙述综述都适用，不可机械套用系统综述结论。

### 投稿映射说明

- 模块 0、1、2 → 题名/署名、摘要、引言；PLOS ONE 须遵守 Title page → Abstract → Introduction。
- 模块 3 → 引言或相关综述比较；模块 4 → 选材/综述方法；模块 5 → 主题综合或 Results。
- 模块 6、7 → Discussion 与结论，可合并；PLOS ONE middle 可重排或改名，独立 Conclusions 可选。
- 模块 8、9 → 材料可用性、伦理正文、系统贡献/利益冲突字段与致谢；PLOS ONE 资助只进系统，不进入 manuscript。
- 模块 10、11 → References 和附录/补充材料；PLOS ONE ending 为 Acknowledgments → References → 适用的补充材料图注。
- 若投《软件学报》，按当时 Word 模板调整章节和前后置信息；这些内部模块不替代官方样式或综述类型审查。
