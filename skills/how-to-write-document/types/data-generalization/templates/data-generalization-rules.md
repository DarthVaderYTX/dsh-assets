# 数据泛化规则模板

## 二、填写示例（虚构，仅示意粒度）

```markdown
# 用户行为日志对外共享数据泛化规则

## 0. 文档信息
- 适用数据集 / 交付物：行为日志分析表 behavior_log（对外共享批次 2026-11）
- 版本：v1.2  审批状态：已评审，待生效
- 责任方：数据平台组 / 安全合规组（审阅人待确认）
- 生效日期 / 失效日期：2026-12-01 / 待确认
- 变更记录：v1.2 新增 search_query 与 tags 规则；影响下游 3 张看板
- 关联材料：数据字典 D-118、共享合同 CT-2026-07、脚本 rules/behavior_log.py

## 1. 泛化目的与适用范围
- 目的：让外部合作方分析行为趋势与转化，同时不出现可定位到个人的设备、位置与查询内容。
- 使用方与允许用途：合作方数据分析团队，仅用于聚合分析与模型训练；禁止重识别、禁止与外部数据拼接。
- 覆盖范围：2026-01 至 2026-10 的行为日志，字段 10 个，约 4,200 万行。
- 不覆盖的字段与原因：event_type 不含个人信息，原样输出。
- 非目标：不做加密，不改变事件口径，不保证不可逆（user_id 可按批次加盐复现）。

## 2. 泛化要求与约束
| 编号 | 要求 | 来源 | 验证方式 |
| --- | --- | --- | --- |
| Q1 | 城市与年龄组合的最小分组 ≥ 50 人 | 内部隐私规范 §4.2 | 分组计数校验 |
| Q2 | 同一 user_id 在同一批次内映射稳定 | 共享合同附件 A | 重复实体一致性抽样 |
| Q3 | 查询文本不得以明文出现 | 合同 CT-2026-07 §3.1 | 正则扫描 |
| Q4 | 金额保留区间语义，误差不超过 1 档 | 业务方确认 | 分桶断言 |
- 性能与成本约束：单批处理 ≤ 2 小时，存储增长 ≤ 10%。
- 格式与命名约束：字段名与类型不变；时间统一为 UTC+08:00、精确到小时。
- 审计留痕要求：记录批次、规则版本、执行人、校验结果，保存 2 年。

## 3. 数据字段定义与表述
| 字段名 | 业务含义 | 类型 / 格式 | 取值域、单位、时区 | 示例（原始） | 敏感级别 | 是否泛化 | 规则编号 | 泛化后示例 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| event_id | 事件唯一编号 | string(32) | UUID | 3f1c…a9 | 低 | 是 | R1 | 8f2e…c1 | 保留可追溯性，重编号 |
| user_id | 用户编号 | string(16) | 16 位十六进制 | u_10086 | 高 | 是 | R2 | 5c9a…7d | 加盐哈希，批次内稳定 |
| event_time | 事件发生时间 | datetime | UTC+08:00 | 2026-10-12 21:43:17 | 中 | 是 | R3 | 2026-10-12 21:00 | 截断到小时 |
| ip | 客户端 IP | string | IPv4 / IPv6 | 203.0.113.77 | 高 | 是 | R4 | 203.0.113.0 | 掩码到 /24 或 /48 |
| city | 城市 | string | 地级市 | 杭州市 | 中 | 是 | R5 | 浙江省 | 映射到省级 |
| age | 年龄段 | int | 0–100 岁 | 27 | 中 | 是 | R6 | 25-29 | 5 岁分桶 |
| device_model | 设备型号 | string | 厂商 + 型号 | iPhone15,3 | 低 | 是 | R7 | Apple / iOS 17 | 映射品牌 + 系统大版本 |
| search_query | 搜索词 | string | 自由文本 | 附近的牙科医院 | 高 | 是 | R8 | 长度 6-10 | 不保留原文，只留长度区间 |
| order_amount | 订单金额 | decimal | 元，两位小数 | 128.50 | 中 | 是 | R9 | 100-500 | 分桶 |
| tags | 用户标签 | array<string> | 最多 10 个 | ["新客","母婴"] | 中 | 是 | R10 | ["新客","其他"] | 保留前 5 个，稀有标签归并 |

枚举对照：
| 字段 | 取值 | 含义 |
| --- | --- | --- |
| search_query | 0 / 1-5 / 6-10 / 11+ | 查询词长度区间（字符） |
| order_amount | 0 / 0-100 / 100-500 / 500+ | 金额区间（元） |

## 4. 泛化规则
| 规则 | 适用字段 / 类型 | 输入 | 转换方法（算法 + 参数 + 阈值） | 输出 | 边界与异常 | 顺序 / 冲突 | 可逆性 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| R1 | event_id | UUID | 用批次盐值做 SHA-256，取前 8 位十六进制 | 16 位字符串 | 非法格式 → 置空并记日志 | 最先执行 | 不可逆 |
| R2 | user_id | 任意字符串 | HMAC-SHA256(key=batch_salt_2026, msg=user_id)，取前 16 位 | 16 位十六进制 | 空值 → 保留空值 | 在 R1 后 | 可逆（持有盐值可复现映射，不还原原值） |
| R3 | event_time | datetime | 截断到小时；时区统一 UTC+08:00 | ISO 时间（精确到小时） | 缺失 → 保留空值 | — | 不可逆 |
| R4 | ip | IPv4 / IPv6 | IPv4 末 8 位清零；IPv6 取 /48 前缀 | CIDR 地址 | 非法 IP → "invalid" | — | 不可逆 |
| R5 | city | 地级市 | 按行政区划映射到省；直辖市映射到自身 | 省级名称 | 未识别 → "其他" | 在 R6 前 | 不可逆 |
| R6 | age | int | 5 岁分桶：18 岁以下 "18-"，65 岁以上 "65+"，其余 "25-29" 形式 | 区间字符串 | 缺失 → "unknown"；>100 → "65+" | — | 不可逆 |
| R7 | device_model | string | 解析厂商与系统大版本；iOS/Android 版本取主版本号 | "厂商 / 系统 主版本" | 无法解析 → "unknown" | — | 不可逆 |
| R8 | search_query | string | 仅保留长度：0、1-5、6-10、11+ | 区间字符串 | 空串 → "0" | — | 不可逆 |
| R9 | order_amount | decimal | 分桶：0、(0,100]、(100,500]、(500,∞) | 区间字符串 | 负值 → "invalid"；空值 → "unknown" | — | 不可逆 |
| R10 | tags | array | 保留前 5 个；命中 top-50 标签保留，否则归并为 "其他" | 数组 | 空数组 → [] | 在 R5 后 | 不可逆 |

- 参数与依据：batch_salt_2026 由安全组保管，按季度轮换（待确认轮换流程）。
- 保持不变字段：event_type（不含个人信息），原样输出。

## 6. 校验、验收与审计
| 检查项 | 方法 | 样本 / 范围 | 通过条件 | 工具 / 脚本 |
| --- | --- | --- | --- | --- |
| 字段覆盖 | 断言字段列表与规则表一致 | 全量 | 10 个字段均有规则或原样说明 | rules/check_fields.py |
| 文本无明文 | 正则扫描 search_query | 全量 | 无中文字符与原始词命中 | rules/scan_text.py |
| 关联一致 | 同一 user_id 抽样比对 | 1,000 个实体 | 映射结果 100% 一致 | rules/check_consistency.py |
| 分布保真 | 分桶前后占比对比 | 全量 | 各档偏差 ≤ 3 个百分点 | rules/dist_compare.py |
```
