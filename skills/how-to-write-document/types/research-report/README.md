# 调研报告

## 一、整体要求与约束

### 文档目的与适用范围

调研报告回答：**要研究的问题是什么，现有来源支持哪些发现与判断，还有哪些不确定性，以及应采取什么行动。** 适用于用户访谈、竞品研究、市场与行业调研、技术与采购评估等，不限于“从几个产品中选一个”。可以建议采取行动、维持现状、分阶段验证或暂缓判断；仅罗列资料而没有分析与判断，不能满足报告目的。

### 结论、证据与篇幅

- 结论简练清晰，明确判断或建议，并给出支撑结论的关键数据与来源。摘要推荐三句：“判断/建议—关键证据—前提/下一步”，不将三句、固定数字个数或 120 字设为硬约束。
- 量化证据说明统计单位、分母、样本范围、时间、口径与来源；质性证据保留原话、上下文与出处，不为了有数字而编造频率、百分比或评分。没有可靠量化依据时用真实事实/原文支撑，并明确不能做何种量化推断。
- 主文简短，保留决策所需内容；更多结论另列表，完整资料、访谈与明细放附录。不能为了简短省略关键矛盾、来源缺口或行动限制。
- 摘要、证据表、分析表和典型例子的数值及口径一致；摘要不得把样本内频次写成总体比例，也不得混用不同版本、地区或时间窗。
- 每项重要结论必须有典型例子支撑：包含研究输入/情境、证据、观察结果、来源、代表性及其对应结论。主动检查反例、相反来源和不适用条件；未发现时如实记录检查范围与方法，不虚构反例或为了填表造数据。

### 来源与证据质量

- 按具体陈述选择匹配来源，而非机械套用“官方高于实测”的统一等级。产品公布的条款应查对应版本的原始文件；实际表现应查匹配环境的测量；用户需求应查合适对象的原始访谈/观察；市场规模应查统计定义、样本与估算方法。
- 同时判断原始性、独立性、时效性、方法透明度、适用条件与利益关系。官方材料适合说明官方承诺，但不自动证明真实表现；实测也不能自动证明全部场景。多个转载同一材料不算多个独立来源。
- 尽可能核对关键争议事实的独立证据；只有单一来源或无法访问原始材料时明确标注缺口。来源不足不是补造证据的理由，也不意味着必须凑齐固定数量的引用。
- “未查到”不等于“不存在”；“访谈对象未提到”不等于“用户没有需求”。负面结论说明检索范围、问法、版本和证据强度。来源冲突要展示差异并分析原因，不能静默选择支持偏好的那一份。

### 分析与比较边界

- 研究维度来自研究问题，不强制一切量化，也不把所有调研都做成选型评分。访谈可用主题与反证分析，竞品可研究定位/体验，市场可分析结构与趋势，选型可用约束和性能比较。
- 比较必须同口径；条件不同则披露版本、地区、样本、测试负载、统计指标等差异，解释是否可归一化。不可比项明确标“不可比”及原因，不通过并排数字制造排名。
- 只有采用加权评分时才需要权重。此时说明维度、尺度、归一化、权重来源、设定时间、缺失处理与敏感性；主观评分不可包装成客观测量。事后调整权重必须披露，关键排名应检查对权重/假设是否敏感。
- 区分事实、受访者观点、作者解释与行动建议；说明局限与替代解释，不把相关关系当因果，也不把少量目的抽样访谈外推为市场普遍规律。

### 表达、追溯与保密

- 明确主要读者与用途：决策者先读摘要、限制和行动，研究/执行者通过方法与附录核查。主文按问题与决策需要保持简短，细节下沉附录但证据链不断；措辞具体克制，避免宣传式语言与无依据泛化。
- 未知的负责人、截止日期、预算、审批状态或资料写“待确认/未提供”，说明影响及核实路径；不为填表编造责任分配、时间承诺和已作决定。模板允许占位符，实际报告应替换真实记录或明确标注缺失。

关键事实与判断用证据编号回指原始来源及具体位置，记录发布/生效日期和采集/访问日期。图表有标题、单位、口径、范围与来源。原话摘录准确，脱敏以稳定编号及授权核查位置保留追溯。所有模板内容均为占位符，不得当成真实调研结果；不得暴露客户身份、未授权访谈、个人信息或受限商业资料。

## 二、整体结构与模板

章节按下列顺序组织，顺序固定；不适用的小节说明原因后省略，不删除整段证据链。

0. 头部信息
1. 结论摘要
2. 研究问题与范围
3. 研究方法与执行记录
4. 来源与证据
5. 分析、比较与关键发现
6. 典型例子与反例检查
7. 不确定性、局限与待验证项
8. 建议、决定与行动计划
9. 参考资料与附录

完整可复制模板见 [templates/research-report.md](templates/research-report.md)，内含空白模板、填写示例、真实示例链接。写作时先取模板，再回到本文「三、各部分写作要求」逐节核对；模板与本文小节一一对应。

## 三、各部分写作要求

### 0. 头部信息

- **目的**：明确报告针对哪个问题、哪个资料时点及哪项决策状态，防止陈旧材料被当成现状。
- **必须内容**：主题、报告编号和版本，作者、执行人及审阅状态，调研起止、资料截止、报告日期，受众与用途、访问限制；涉及价格、政策、功能与市场时说明适用版本/地区/时间边界。
- **表达/图表**：简短字段列表或表；截止日期与访问日期分开，重要版本给稳定标识。
- **验收**：读者能判断是否适用于当前决定、能联系谁核查，以及报告是建议稿还是已批准结论。
- **禁忌**：用“目前”“最新”代替时间；把采集日期当来源发布日期；隐藏资料已过期或审阅未完成。

### 1. 结论摘要

- **目的**：直接回答研究问题，并说明证据支持什么行动，而不是用“各有优劣”代替判断。
- **必须内容**：结论编号、明确判断/建议、关键数据或质性事实及来源、成立前提、关键不确定性和下一步。无法判断时指出缺什么、为何影响结论及如何补证；判断可以是暂缓、验证需求或缩小行动范围，不强制选出赢家。
- **表达/图表**：推荐三句完成“判断/建议—证据—前提/行动”。主段短，更多结论另列表；不塞进检索过程或背景。数字数量取决于证据需要，质性发现可直接引用准确原话与范围。
- **验收**：摘要与第 4、5 节逐项一致，每项重要结论有第 6 节实例；建议的力度与证据强度相符，读者知道能做什么、暂不能做什么。
- **禁忌**：只有形容词没有依据；质性访谈被强造为百分比；不可比数字进摘要排排名；有限样本被写成“普遍如此”。

### 2. 研究问题与范围

- **目的**：定义何为“回答了问题”，并防止范围无限扩张或事后为了偏好缩小范围。
- **必须内容**：主问题与必要子问题、提出背景和决策用途、目标受众/人群；覆盖对象、地区、行业、场景、版本、时间窗；不覆盖项及原因、必要术语与成功回答标准。需要比较时说明备选对象选择依据，而非只调研已偏好的对象。
- **表达/图表**：范围表或“问题—所需证据—用途”表。用户研究可以写行为与需求问题；市场研究写口径和地域；竞品研究写研究维度；不机械转成产品评分题。
- **验收**：研究方法和证据能逐一对应问题，范围边界使结论外推可检查。
- **禁忌**：“全面了解市场”而无边界；遗漏关键竞品/人群却声称完整；把范围排除写成已证明不重要。

### 3. 研究方法与执行记录

- **目的**：说明资料如何进入报告、样本如何产生、分析如何执行，使选择偏差与方法限制可见。
- **必须内容**：方法选择理由、检索词/平台/时间/语言与停止范围；来源纳入/排除标准；访谈/观察对象招募、筛选、人数与构成、提纲、授权和记录方式；实测环境/配置/脚本；二手数据的统计定义与方法。记录实际执行、偏离、资料处理和排除情况。
- **表达/图表**：执行表及资料/样本流转表，说明候选数、排除数、最终数和原因；方法资源放附录。按实际所用方法展开，不强制每项都执行。
- **验收**：另一研究者能复走主要过程、解释为何采用这些对象和资料，关键处理规则及版本可定位。
- **禁忌**：只写“网上搜索、多方访谈”；事后删除不支持结论的访谈；目的抽样冒充随机抽样；未经测量推断访谈“达到饱和”。

#### 访谈、观察与质性分析

保留脱敏原话和上下文，说明访谈提问是否引导、记录是否完整、编码/主题归纳方法、分歧处理与反证搜索。出现次数可记录，但要区分受访者数、提及次数与事件数，不把重复提及当作独立支持人数；非概率样本不直接外推总体占比。没有频次记录就保留质性描述，不倒推数字。

#### 数值数据、实测与清洗

说明统计单位、抽样框、分子分母、时间窗、货币/税费/计费口径；记录去重、缺失、异常、排除、单位转换与归一化规则、处理前后数量和影响。实测需环境、版本、负载、执行人、日期和失败处理。只有在设计与数据支持时使用统计推断，并说明方法与限制；不凭空补区间或显著性。

### 4. 来源与证据

- **目的**：将论证所依赖的事实和原始出处绑定，让读者分辨“谁说的、说了什么、可相信到什么程度”。
- **必须内容**：来源 S 编号与证据 E 编号，作者/机构、标题、原始链接或授权位置、章节/页码/段落/时间戳，发布/生效与访问日期，版本、适用条件；原文或可复核数据、验证状态、利益关系、独立性、来源缺口和冲突。
- **表达/图表**：证据表每行只承载清楚的一项事实，摘录保持原意，删节可识别；来源索引存完整书目信息。区分事实、受访者观点、厂商宣称、作者推断，编号不要混用。
- **验收**：重要事实能定位原文，不仅指向网站首页；结论可沿 C→F/E→S 回溯；单一来源、未复现和无法访问原始材料明确可见。
- **禁忌**：转载算独立交叉验证；官方承诺直接当实测结果；截断原话改变含义；写“业内普遍认为”无来源。

#### 按陈述匹配来源

对公布价格/限制优先核对对应地区与版本的条款，对真实性能考察匹配条件的测量，对需求/体验核对原始访谈与观察，对市场数字核对统计范围与估算模型。不存在统一的“官方必胜”排序：官方和实测冲突时，先核对它们是否在回答同一问题，再报告差异、各自局限与待验证项。厂商演示可作为“厂商展示了什么”的证据，但不自动支持普遍可用；注明提供方和未独立复现状态。

### 5. 分析、比较与关键发现

- **目的**：从证据形成对研究问题的回答，而不是简单转述资料或只写最终赢家。
- **必须内容**：分析维度及依据、关键发现编号、证据链、分析方法与推理、研究含义；矛盾证据、替代解释和不确定性。比较时记录所有关键对象，包括不采用的选项与理由；不涉及选型时按主题、行为、市场结构/趋势或竞品定位展开。
- **表达/图表**：同口径比较用表，主题分析可用“主题—原话/观察—解释—影响”，市场趋势可用带来源和口径的图。质性差异准确描述，不强制造数值；缺失不是零。
- **验收**：每项发现均有证据与推理，事实与解释分开；摘要数字与分析表一致，研究问题被直接回答，可比性和局限可见。
- **禁忌**：链接堆砌代替分析；只写赢家不写替代对象；峰值与平均值比较后排名；少量访谈归因“市场需求下降”。

#### 同口径比较与数值解释

核对统计单位、分母、样本范围、地区、日期、版本、负载与指标定义。条件不同但可转换时给转换公式与假设，同时保留原值；不能转换则标“不可比”并解释，必要时只做条件化描述。绝对差与相对变化分列：比例差通常用百分点，相对变化需基线；基线为零或不稳定时说明不适用。市场份额、用户数、事件数和收入不能互相替代；推算值标明模型/假设，不当作观测值。

#### 仅采用评分时：权重与敏感性

写清评分目的、维度、尺度、归一化、权重来源（决策者偏好、业务约束或研究依据）、设定时间与缺失处理。主观等级说明判定标准，不制造伪精度。检查合理权重、假设或关键数据变化是否改变排序；敏感时给条件化建议而非单一总分胜出。后改权重应记录原因与影响；不用评分则无需权重。

### 6. 典型例子与反例检查

- **目的**：用可核查实例解释发现如何发生、对应什么结论，并检验是否存在相反情境或边界。
- **必须内容**：每项重要结论关联例子 ID、研究输入/情境（访谈问题、用户任务、竞品流程、测量条件等）、原文/行为/数据证据、观察结果、来源具体位置、选取方式与代表性、支持或限制哪条结论及理由。必要时记录判定标准与判定者。
- **表达/图表**：紧凑实例表或“输入/情境—证据—结果—来源—代表性—对应结论”证据块。访谈保留脱敏原话和上下文；竞品截图写版本、日期与任务；实测样本写参数、环境、记录位置。示例一律用占位符，不生成貌似真实的访谈和数据。
- **验收**：每项重要结论同时映射研究范围内的总体证据与真实实例，能从来源核查事实及解释；代表性说明是常见主题、特定子群或极端案例，并给选取依据。例子只能支持其范围，不替代总体证据。输入没有实例时明确证据缺口、结论限制及补证路径，不仅留空模板，也不编造原话或案例。
- **禁忌**：把宣传图当成独立验证；把个别访谈改写成“用户普遍认为”；虚构受访者原话；把未查到的反例写成不存在。

#### 反例、相反来源与不适用条件

主动检查异议访谈、未采用对象、相反资料、失败任务和边界场景，记录检查范围与方式。发现反例时分析是否修正结论、限制外推或改变行动；没有发现时写“在〈检索/访谈/测量范围〉内未发现反例”，指出尚未覆盖什么。不适用条件应有依据，假设性的风险标“待验证”，不能冒充已观察反例。

### 7. 不确定性、局限与待验证项

- **目的**：使读者知道哪些发现已较可靠，哪些需要额外证据，以及缺口如何影响行动。
- **必须内容**：未覆盖范围、原始来源缺失、单一来源、资料过期/冲突、样本偏差、测量条件不足、质性解释歧义、估算假设等；每项说明已检查范围、原因、影响哪条结论、可能改变什么建议及补证方式和优先级。
- **表达/图表**：缺口表按决策影响排序，区分“未搜索”“未查到”“查到但未核实”“已知冲突”“不适用”。不能量化不确定性时用具体限制描述，不强打可信度分数。
- **验收**：决定性缺口进入摘要与行动前提；待验证项有可执行方法，读者不会把信息空白误认为负面事实。
- **禁忌**：泛写“资料有限”不解释影响；“没查到支持私有化”写成“不支持私有化”；隐瞒相反来源；把假设写成已验证事实。

### 8. 建议、决定与行动计划

- **目的**：把研究发现转成可执行、可检查且与证据强度相称的行动，不仅适用于选型。
- **必须内容**：明确建议、依据与前提，可选方案及取舍；负责人、截止/触发条件、验收和退出条件、风险及监控；已作决定记录决策人/日期/状态，和待批准建议分开。对证据不足的事项，给补证或小范围试点路径。
- **表达/图表**：行动表连接 C/F/E 编号。访谈可提出设计假说与验证动作；竞品可提出体验/定位调整；市场可提出渠道或进入验证；选型可提出候选与约束。不强制报告得出“选 A”。
- **验收**：执行者知道做什么、为何做、何时验证和如何判定；关键假设变化时知道何种建议需要重审。
- **禁忌**：“结合实际”“持续关注”无动作；建议范围超过研究覆盖；把作者建议冒充批准决定；不稳定排名写成无条件最终方案。

### 9. 参考资料与附录

- **目的**：使来源和研究过程可回查，同时让主文保持简短。
- **必须内容**：完整来源索引（S 编号、作者/机构、标题、版本、发布/访问日期、链接/授权位置），证据具体定位；检索记录、访谈提纲、脱敏记录、编码规则、分析/清洗脚本、实测配置与完整结果、推算模型/评分权重、排除资料与修订历史。
- **表达/图表**：索引表与按主题整理的附录；网页易变化时记录可授权访问的快照/归档，受限资料说明获取方式。正文通过稳定编号和有效链接对应，不堆放无用途链接。
- **验收**：C→F/E→S 的追溯链无断点，读者能复走关键分析，无法公开的环节有权限限制和核查路径。
- **禁忌**：引用不支持正文的资料；只给首页无定位；链接失效不标注；脱敏后无法核查或未经授权公开原始访谈。

## 四、交付前检查

- [ ] 头部版本、责任人、资料截止与决策状态明确，价格/政策/功能等有适用时点与条件。
- [ ] 研究问题、范围、不覆盖项和方法对应，报告不局限于机械选型，也不是只罗列链接。
- [ ] 摘要短且有明确判断/建议、真实关键数据或质性证据及来源、前提和下一步；更多结论另列表，不强限数字个数或字数。
- [ ] 数值与证据/分析表一致，统计单位、分母、单位、时间窗、版本及绝对/相对差异清楚；不可比项未用于误导性排名。
- [ ] 来源按具体陈述匹配，原始性、独立性、时效性、利益关系与适用条件明确；转载没有被算成独立验证，缺口与冲突如实记录。
- [ ] 方法、筛选、清洗/排除、质性编码与实测配置可复查；原话准确，非概率样本未外推总体，未强造数字或统计检验。
- [ ] 分析从证据到发现到结论有推理链，事实/观点/解释分开，未采用对象或相反发现没有被选择性删除。
- [ ] 只有采用评分时使用权重，来源、设定/调整记录、尺度、缺失处理和敏感性清楚，没有主观评分伪精度。
- [ ] 每项重要结论有可追溯典型例子，输入/情境、证据、结果、来源、代表性及支持点完整；反例检查有范围，未发现如实说明，不造反例。
- [ ] “未查到”未写成“不存在”；局限、来源缺口、待验证事项和行动条件一致，建议与已批准决定分开。
- [ ] 行动有依据、负责人、时限/触发条件与验收/退出条件；资料变化或假设不成立时有重审安排。
- [ ] 实际交付的模板占位符已替换为真实记录或明确标注缺失及影响；未知负责人、日期或决定未虚构成承诺。围栏成对、表格可读、链接和编号可定位，来源与访谈权限/脱敏满足要求。
