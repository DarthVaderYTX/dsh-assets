# 实验报告

## 一、整体要求与约束

### 文档目的与适用范围

实验报告回答：**在什么条件下观察到了什么变化，证据是否足以支持某项判断，以及下一步应如何行动。** 适用于在线随机分流实验、离线评测、消融、性能测试、参数或提示词比较、因子实验等。离线评测只是实验的数据获取与评价方式，遵循同一报告结构，不另立一种报告规范。负结果、失败实验和暂不能判断的实验同样应记录。

### 结论与证据

- 结论必须简练清晰，明确判断或建议，并紧接支持该判断的数据与来源、适用范围及重要风险。摘要推荐用三句分别表达“判断/建议—关键证据—边界/下一步”；这是写作建议，不是三句、固定数字个数或 120 字的硬上限。
- 主文只保留理解与决策必需的证据。更多结论另列表，完整明细、日志和次要分析放附录；不能为了简短隐藏负结果、护栏恶化或决定性限制。
- 结论、结果表、图、实例和附录必须使用一致的版本、口径与数值。四舍五入差异需可解释，修订应同步传播，不允许摘要使用另一个分母或时间窗。
- 每个重要结论必须有可追溯的典型例子支持，交代输入、证据、结果、来源、代表性及其对应结论。例子用于解释现象和边界，不能代替总体数据，也不能单凭成功样本推断总体效果。
- 主动检查反例、失败样本和不适用条件。没有发现反例时，如实写“在〈检查范围与方法〉内未发现反例”，并说明覆盖限制；不得把未发现写成不存在，更不得为了填模板伪造反例或数据。

### 设计与推断边界

- 单变量比较与因子实验均可。单变量比较要说明控制条件；因子实验要说明因素、水平、组合、主效应与交互作用的识别方法。多个因素共同变化但缺少可识别设计时，只能判断方案组合，不能把效果错误归因到某一个因素。
- 随机分流实验才检查样本比例失配（SRM），并说明分流单位、预期比例、实际比例、检查方法及异常影响。非随机实验不机械套用 SRM，而应检查选择偏差、配对、时段、环境与样本可比性。SRM 异常应调查原因并评估有效性，不作未经调查的自动结论。
- 置信区间、显著性检验、功效分析及多重比较处理，应根据数据类型、统计单位、依赖关系、抽样与实验设计选择。适用时报告方法、效应大小与不确定性，不凭空补 p 值或区间；不适用或未执行时明确说明。无统计检验依据的样本只能支持相应范围的描述性判断，不写“统计显著”“证明有效”或“证明无效”。
- 预设假说、指标、阈值、样本规划与停止规则，和事后提出的探索分析必须分开。缺少预注册或执行前记录时写“未预注册/无法确认预设”，不得回填成事前设定。探索结果可作为风险匹配的决策信息，但要标明探索属性、不确定性和独立验证需求，不能包装成确认性证据。
- 重复次数由波动来源、测量稳定性与推断目标决定。固定重复两三次不等于证据充分，单次结果也不因补一个 bootstrap 区间就自动可靠；重采样不能弥补不代表总体的样本或错误的独立性假设。

### 表达、追溯与保密

- 明确主要读者及用途：决策者先读摘要、风险与行动，执行/复核者通过方法与附录追溯。篇幅按决策复杂度安排，主文精简、方法细节可下沉但不能断开证据链；语气克制、具体，避免口号和未经支持的因果措辞。
- 未知的负责人、日期、阈值、审批结果或数据写“待确认/未提供”，并说明影响；不为填行动表虚构责任分配、时间承诺或决定。模板允许占位符，实际报告须替换真实记录或明确标注缺失及补证计划。

- 区分观察事实、统计推断、机制解释和行动建议；措辞与证据强度匹配。“未检出差异”不等于等效；“没有观察到风险”不等于没有风险。
- 每个关键数字说明单位、分母、统计单位、聚合方式、时间窗和来源。比例变化区分百分点与相对变化；不能把绝对差写成相对提升。基线为零或分母不稳定时，不给误导性的相对变化。
- 图表应有自解释标题、单位、口径、样本数和来源，按需要展示分布、波动或适用的不确定性，而非所有图强制加误差棒。引用定位到数据快照、表、脚本、日志或样本记录，并记录版本。
- 脱敏不破坏追溯：提供稳定编号与授权核查位置，不泄露密钥、个人信息或受限数据。本规范所有模板内容均为占位符；不得将其当成实测事实。

## 二、整体结构与模板

章节按下列顺序组织，顺序固定；不适用的小节说明原因后省略，不删除整段证据链。

0. 头部信息
1. 结论摘要
2. 问题、假说与决策规则
3. 实验设计与数据获取
4. 数据处理与分析方法
5. 结果与效应
6. 典型例子、反例与边界检查
7. 有效性、局限与归因
8. 决定与后续行动
9. 复现资料与附录

完整可复制模板见 [templates/experiment-report.md](templates/experiment-report.md)，内含空白模板、填写示例、真实示例链接。写作时先取模板，再回到本文「三、各部分写作要求」逐节核对；模板与本文小节一一对应。

## 三、各部分写作要求

### 0. 头部信息

- **目的**：使报告和某一次实验、某份数据及某个决策状态绑定，避免版本混用。
- **必须内容**：名称与稳定 ID，报告版本、负责人和执行人、审阅状态；执行起止、数据截止与报告日期（涉及时刻应含时区）；方案/基线/数据版本、报告用途、受众和保密等级。失败、终止、补跑也要注明状态与原因。
- **表达/图表**：用紧凑字段表或列表，不写长背景；日期与时间采用一致格式，版本给稳定标识，访问入口放复现索引。
- **验收**：读者能辨别“哪次实验、谁负责、使用哪份数据、是否可据此执行”，同名补跑可区分。
- **禁忌**：用“最新版”“最近测试”代替版本/日期；把报告日期当实验日期；把未审阅稿标成已批准。

### 1. 结论摘要

- **目的**：先给出可理解、可核查且有边界的判断，让读者不读全过程也能掌握决策含义。
- **必须内容**：结论编号、判断或建议、最关键的实际数据与来源、适用条件、重要护栏风险和下一步。证据不足时明确“现有数据不足以判断〈问题〉”，指出缺失证据及可执行的补证动作；不是以含糊乐观语收尾。
- **表达/图表**：推荐三句，依次回答“判断是什么”“哪项证据支持”“在哪些条件下成立、下一步做什么”。数据选择以支撑判断为准，不限制固定个数；更多结论用短表，避免在摘要堆方法与背景。
- **验收**：摘要的方向、数值、分母、单位、来源与第 5 节逐项一致；重要风险没有被省略；每项重要结论能追到第 6 节的实例。
- **禁忌**：只说“效果不错”；只报数字不作判断；用无依据的显著性或机制措辞；把样本内结论写成所有场景的结论。

### 2. 问题、假说与决策规则

- **目的**：说明为何实验、何种结果改变决定，并使读者分辨事前规则与事后解释。
- **必须内容**：研究问题、决策对象与使用者、基线及候选方案；假说来源、预期方向（有记录时才写预期幅度）；主指标或多个共同主指标的关系、护栏、指标定义和优先级；成功/风险阈值、样本规划、观察窗口、停止与中期分析规则。所有设定注明记录时间与来源，实际执行偏离单列。
- **表达/图表**：规则表列“项目—设定—记录位置/时间—实际执行—预设/探索”。阈值说明业务或统计依据；共同主指标说明联合判定方式，不强制唯一主指标。
- **验收**：读者能够用实际结果复算决策；执行前记录与事后新增分析可区分。没有记录的字段明确缺失，不能推断成预注册。
- **禁忌**：跑完再选赢家指标而隐瞒；预设与探索混写；承诺禁止中期查看却实际择机停止而不披露；把探索分析绝对排除于所有决策之外。

### 3. 实验设计与数据获取

- **目的**：说明差异如何产生、测量如何获得，以及这种设计能支持什么比较。
- **必须内容**：设计类型、因素/水平/组合、基线、控制条件与环境；抽样框、纳入范围、统计单位、分配单位、样本量依据、配对/重复测量关系；执行流程、周期、随机种子、测量工具与原始数据来源。说明样本是否代表目标人群，以及样本规模对推断的限制。
- **表达/图表**：设计矩阵、条件表及数据流程图。把用户数、请求数、任务数、运行次数、评分次数分开，不能把重复调用当作新增独立样本。
- **验收**：另一执行者能按记录获得相同条件的数据；因素变化与控制关系清楚，结论强度与设计匹配。
- **禁忌**：多因素共同改变后归因单一变量；隐瞒组间硬件/负载/时间差；只有样本数而没有统计单位或抽样依据。

#### 在线随机分流与其他设计

随机分流写清比例、哈希键、跨会话一致性、实验污染与 SRM 检查方案。非随机的前后比较、匹配或观察性设计，说明同期变化、选择偏差及控制方法。因子实验说明因素组合覆盖及交互作用如何估计；缺少某些组合造成无法识别时直接限制归因。

#### 离线评测的数据方式

记录评测集来源、快照、许可、筛选/分层、泄漏与训练集污染检查、线上分布关系；模型、提示词、解码参数、工具配置、重试与失败计分方法。评分来自 rubric 时，记录版本、维度、分值含义、标注人数/角色、盲评、分歧处理及适用的一致性检查；自动评委说明评委模型/提示词版本、校准与偏差。确定性任务不机械重复；随机输出或环境波动应说明重复/重采样设计及充分性依据。

### 4. 数据处理与分析方法

- **目的**：让原始记录到结果之间的每一步可复核，防止清洗或统计选择改变结论而不可见。
- **必须内容**：原始数据与分析集版本；去重、缺失、异常、失败/超时、无效评分的规则；清洗/排除依据及是否预设；处理前后数量、各组排除数量和原因、保留样本范围；指标公式、分母、统计单位、聚合与权重、分析代码与版本。
- **表达/图表**：样本流转表和指标字典；公式定义分子/分母，伪代码或命令指向可执行脚本。事后处理给出合理性及处理前后/替代规则的敏感性分析（可行时）。
- **验收**：原始数、排除数和分析数能对账；第三方能复算核心表；失效请求是否计入成功率等关键口径无歧义。
- **禁忌**：静默删除失败样本；只对某组清洗而不说明；为得到好结果改规则；用请求级样本数冒充用户级统计有效样本数。

#### 推断方法的适用性

说明估计目标、检验/区间方法、置信水平及适用假设，处理配对、聚类、重复测量与非独立样本；涉及多重检验或多次中期分析时说明控制策略，未校正则披露误报风险。Bootstrap 写清重采样单位与次数依据。方法不适用、未执行或样本不足时明确限制，只给可支持的描述性统计；不得补造 p 值/区间，也不得把不显著直接写成等效。

### 5. 结果与效应

- **目的**：完整呈现观察到的效果、代价与不确定性，而不是只展示“最好”的指标。
- **必须内容**：主指标、护栏和重要负结果；各组值、绝对差、适用的相对变化、分母/样本数、统计单位、数据来源和版本；适用的区间/检验或未计算的原因；预设结果与探索结果的标识。记录实际时长、提前停止、补跑及与计划的偏离。
- **表达/图表**：核心结果表保持精简；需要时补分布、尾部、分层、运行间波动与因子效应/交互图。每图写清轴单位、样本范围、来源，误差条仅在有定义与计算依据时使用。缺失值写“未测/不可比/不适用”及原因，不用零替代。
- **验收**：表内各差值可复算，摘要能逐项回指；总体和分层口径一致或差异得到说明；没有统计依据的结果未被标成显著。
- **禁忌**：只给 p 值不讲效果大小；只给相对变化掩盖很小的基线；均值掩盖决策相关的长尾；用探索筛选的最佳子组代表总体。

#### 数值与结论对齐

绝对差为“实验值 − 基线值”，比例指标的绝对差通常用百分点；相对变化为“差 / 基线值”，需注明基线及适用条件。方向解释依指标含义确定，时延下降不能因差值为负而写成退步。实际业务价值与统计证据分开：统计可检出的微小差异未必值得上线；区间过宽或护栏风险未消除时应限制建议。

### 6. 典型例子、反例与边界检查

- **目的**：把重要结论落到可核查的事实剖面，并检验哪些样本、情境或条件会限制结论。
- **必须内容**：每项重要结论关联典型例子，含样本 ID、输入与环境、基线/实验实际输出或测量证据、结果判定、判定标准与执行者、来源位置、选取方式和代表性。离线评分例子含相关 rubric 项、实际得分、分歧及处理记录（如有）。
- **表达/图表**：短证据块或实例表；输入/输出较长时摘录关键部分并链接完整记录。截图应注明条件与定位，不以截图替代解释。所有格式示例使用占位符，不提供貌似真实的样本 ID 或结果。
- **验收**：每项重要结论同时映射总体证据与真实实例，读者能根据原始证据理解“该例子支持 C〈编号〉的哪一点”；例子分布位置有依据，不能因主观觉得典型而声称代表总体。输入没有可用实例时明确证据缺口、影响与补证方式，不能仅留空模板冒充完成，也不能编造实例。
- **禁忌**：只选最佳案例；将演示样本冒充实验样本；虚构失败例子；用一个成功例子证明平均提升；以个别实例推翻总体统计而不查口径。

#### 反例与边界的记录

检查失败、退步、分歧、尾部和关键子群，说明范围、方法、发现及其对结论的影响。发现反例不必机械否决总体结论，但必须修正过强措辞或行动条件；没有反例则写未发现及检查范围。未覆盖场景只能写“未验证”，不能包装成已观察到的反例。

### 7. 有效性、局限与归因

- **目的**：说明证据何时可信、可推广到何处，以及哪些机制解释仍不确定。
- **必须内容**：内部有效性（随机分流适用的 SRM、污染、同期改动、测量漂移等）、外部有效性（人群、任务、地区、版本、时间窗）、统计/测量局限（样本、依赖、评分偏差等）；每项威胁的证据、已处理情况、残留影响；替代解释、归因依据与未确认机制。
- **表达/图表**：威胁表列“问题—证据—处理—剩余影响—限制哪条结论”。分层、消融、因子分析或机制样本只能支持其实际识别范围，不强行给无依据的贡献排名或百分比。
- **验收**：核心限制进入摘要和行动条件；“已排除”有检查证据；不能识别的单因素效果明确未识别。
- **禁忌**：将相关性写成因果；用 case 故事代替归因证据；泛泛写“样本有限”却不说限制哪项判断；把未验证机制写成定论。

### 8. 决定与后续行动

- **目的**：将证据转成与风险相匹配的实际行动，区分报告建议与已批准决定。
- **必须内容**：上线/灰度/保持基线/停止/补证等建议，依据、前提与风险；已作决定注明决策人、日期与状态；行动负责人、时间或触发条件、验收口径、监控、回滚/停止条件；证据不足时列补证优先级。
- **表达/图表**：行动表优先，说明各步骤如何消除不确定性。探索发现可以支持小范围可回滚试点，但注明风险与验证要求；高风险决定需更强证据。
- **验收**：执行者知道做什么、何时结束、何种结果通过、何时撤回；行动与结论及护栏一致。
- **禁忌**：“继续优化”而无负责人/目标；把建议写成审批结果；护栏恶化仍建议无条件全量；缺证据却不给补证路径。

### 9. 复现资料与附录

- **目的**：提供复算与复跑入口，同时避免让主文承担全部明细。
- **必须内容**：数据快照与校验标识、获取权限、脚本/代码版本、依赖/环境、完整命令与配置差异、随机种子、执行日志、评分规则和记录、完整结果/分层/样本索引、预设记录、偏离与修订历史。原始数据不能共享时说明限制及授权核查方式。
- **表达/图表**：来源索引列“编号—资源—版本/日期—精确位置—访问权限”；命令用代码围栏，凭据用占位符。附录与正文通过稳定编号或有效链接对应。
- **验收**：按说明能找到并复算关键结果；不能复现的环节说明原因与对可信度的影响；负结果和放弃方案保留记录。
- **禁忌**：只列工具名称不列参数；链接指向会漂移的“最新数据”；附录与正文用不同快照；暴露凭据或未经授权的样本内容。

## 四、交付前检查

- [ ] 头部完整：实验、版本、负责人、起止/截止及状态明确，时间含所需时区。
- [ ] 摘要简练，给出明确判断/建议、关键数据与来源、适用边界及重要风险；更多结论另列表，不用武断字数或数字数量限制。
- [ ] 每条重要结论与结果表、图、附录的数值、单位、分母、统计单位、版本、方向一致；绝对/相对变化可复算。
- [ ] 预设与探索分开，预注册缺失没有回填，规则偏离、补跑、中期查看和停止情况已披露。
- [ ] 设计能支持所声称的比较/归因；随机分流才做 SRM，因子实验交互与组合效应没有错误归因。
- [ ] 数据来源、抽样、清洗、排除、失败计分与分析集数量可追溯；复现方法、参数与权限完整。
- [ ] 区间/检验符合数据与设计，未计算或不适用如实说明，无伪造 p 值/区间；重复次数没有被当成充分性的保证。
- [ ] 主指标、护栏、负结果、分布/分层及探索结果按决策需要呈现，样本不足与不显著未被误写成普遍有效或等效。
- [ ] 典型例子覆盖重要结论，输入、证据、结果、来源、代表性与判定完整；反例与边界检查有范围，未发现如实写，无虚构数据。
- [ ] 局限、替代解释、机制未确认与外推边界明确，行动有负责人、验收及风险/回滚条件。
- [ ] 实际交付中的模板占位符已替换为真实记录，缺失信息明确标注及说明影响；未知责任人、时间或决定未编造成承诺。Markdown 围栏成对，表格可读，链接与编号可定位，敏感信息已处理。
