# 论文写作规范

## 一、整体要求与约束

### 用途、范围与读者

- **必须**：围绕可识别的研究问题，提出能够被证据、推导或系统性文献分析支持的学术贡献。论文不是把实验报告换成学术词汇，也不是项目开发过程、产品宣传或资料汇总。
- **必须**：区分原创研究、方法/系统论文、理论论文与综述论文。本文默认期刊论文；学位论文、会议论文的篇章和提交要求应另外按学校/会议指南映射，不能直接宣称符合其要求。
- **必须**：写给编辑、领域审稿人和未来复核研究的读者；解释跨领域读者必须知道的术语，同时提供专家核查所需细节。默认中文起草，国际英文期刊按目标语言写作，不能交付中文稿却称可直接投稿。
- **建议**：先形成一条主线——研究缺口 → 问题 → 方法/论证 → 证据 → 贡献与边界；多个贡献须围绕这条主线，不强凑固定数量的“创新点”。

### 学术证据与诚信

- **必须**：区分研究事实、理论假设、推导、统计推断、解释和未来工作。原创性和“首次”“最优”“显著”等主张必须有相应检索、比较或检验依据；查不到既有工作不等于不存在。
- **必须**：结论简练、明确，紧接支撑判断的关键数据、证明结果或综合证据；量化结果注明基线、分母、单位、变化与条件，理论结果注明定理及假设。不得把推测机制、相关性或样本内优势写成因果或普遍规律。
- **必须**：每个关键贡献在正文中对应可定位的证据；适用时提供典型样本、反例、证明中的构造或文献实例，说明来源与为何具有解释价值。例子不能替代总体统计、正式证明或完整文献合成。
- **必须**：参考文献真实且支持所引用的具体陈述；核对题名、作者、年份、出处、DOI及版本，不猜 DOI、不拼造文献、不以二手引用冒充读过原文。预印本、修订、更正和撤稿状态须如实标识。
- **必须**：不造数据、访谈、图像、实验配置、统计显著性、伦理批号、注册信息或作者同意；缺失写待确认，并说明是否阻塞投稿。研究未完成时只能交付大纲、研究计划或明确未完成的草稿。
- **必须**：尊重署名、版权与数据许可；所有作者核实贡献和最终稿。不得代用户认定署名顺序、资助、利益冲突或审批情况；AI辅助使用按目标期刊政策披露，作者对内容负责，不把AI列为可承担责任的作者。
- **条件适用**：涉及人类参与者、动物、敏感个人数据、受限场所或实验材料时，说明相应伦理审批、知情同意、豁免依据和隐私保护；“公开可见”不自动等于允许任意使用。

### 方法、统计与复现

- **必须**：研究设计和证据强度匹配。方法/系统论文给公平基线、环境、数据划分、资源预算和失败处理；理论论文给定义、假设、命题、证明及复杂度范围；综述给检索范围、选择标准、质量评估及合成方法。
- **条件适用**：报告统计单位、样本规划、重复和随机性、效应大小及适当的不确定性。独立性、配对关系、多重比较、中期查看和事后探索须交代；不机械添加 p 值、置信区间或“重复三次”。未检出差异不等于等效。
- **必须**：数据、代码、模型、材料与分析步骤可追溯；版本、参数、预处理、排除、计算环境与授权入口足以支持复核。不能公开时说明具体限制及获取途径，不虚构仓库或承诺已经开源。
- **条件适用**：按研究类型核对报告规范，例如试验、观察研究、系统综述等；规范适用不代表已执行、已注册或已获认证。

### 学位论文（毕业论文）

- **必须**：学位论文的交付约束来自**学校/院系**，不是期刊。字数、章节顺序、字体字号、行距、层级编号、题注位置、引用体例、声明页、打印与提交格式，一律以当届官方模板与院系通知为准；学校模板与本文默认结构冲突时改结构，不保留"更适合发表"的写法。
- **必须**：写作前取得三份材料——当届论文模板/写作规范、院系补充规定、入学年级培养方案。三者版本不一致时按最新通知执行；仍不确定的格式细节咨询院系或导师，不自行推断。
- **必须**：字数要求按院系执行，不套用期刊篇幅判断。部分学校不设校级字数下限而由院系规定，此时仍需满足院系的实质内容要求，不能以"无下限"为由压缩论证。
- **必须**：区分过程节点与写作任务。开题、中期、查重、答辩、终稿提交各有截止时间；论文正文的完整度要与所处节点匹配，未完成的实验或系统不得写成已完成，查重与评阅结果不由作者填写。
- **必须**：原创性声明、使用授权说明、AI 工具使用披露按学校规定签署或填写，日期与签名真实；指导教师评语、成绩评定表、评阅意见由教师或评阅人完成，不代填、不预设结论。
- **建议**：学位论文的贡献表述以"完整、可复现、方法得当"为主，不必追求期刊式的"首次/最优"卖点；但同样要给证据、给边界，避免只有工作量没有判断。
- **条件适用**：涉及匿名评审时，按规定版本去除姓名、致谢、作者信息与元数据；送审版与答辩版、终稿版的差异要留痕。

### 风格、篇幅与期刊预设

- **必须**：论文正文遵循学术论证顺序，摘要先概括发现；不能套用内部汇报的“开头请求批准”。结果回答“发现了什么”，讨论回答“为何如此、意味着什么、还有哪些解释”。
- **建议**：一段解决一个论证任务，采用“问题/语境—证据—局部判断”的组织方式；标题和图表传达研究内容，避免营销式命名、无意义缩写和空泛背景。
- **必须**：篇幅取决于目标期刊和文章类型，不统一设页数或引文数量。图表、公式、术语、中英文摘要与正文口径一致，图表不能只贴截图且无法核查。
- **必须**：以下模板是本 skill 的内容预设，不是官方 Word/LaTeX 排版文件。已参考的官方指南记录于本文末；投稿前重新核对目标期刊、栏目、版本、语言、篇幅、匿名规则、引用格式、声明位置、图表及补充材料要求。某一期刊要求不得推广到所有论文。
- **必须**：公开指南中可能含旧FAQ或相互冲突条款；涉及投稿文件格式、费用、署名变更等实际提交事项，优先核对最新明确通知与投稿系统，冲突未解决时咨询编辑部，不擅自选择有利条款。

## 二、整体结构与模板

### 预设选择

| 预设 | 主要用途与风格 | 模板 | 依据及限制 |
|---|---|---|---|
| 本科毕业论文（学位论文） | 中文撰写、按学校模板组织，强调完整论证、规范体例与过程节点 | [本科毕业论文](templates/undergraduate-thesis.md) | 对照北大经院、清华两个校级口径；**不是官方模板**，提交前必须下载当届模板 |
| 国内中文研究论文 | 研究问题、国内外比较、技术贡献、方法与验证逐层论证 | [中文研究论文](templates/chinese-research.md) | 参考《软件学报》；非其官方排版模板，也不代表全部中文期刊 |
| 国际实证研究论文（IMRaD） | Introduction / Methods / Results / Discussion，强调证据与复现 | [国际实证论文](templates/international-imrad.md) | 整份模板与示例均用英文；参考 PLOS ONE，栏目与声明位置以目标期刊为准 |
| 综述论文 | 以问题和分类框架组织文献，透明说明检索与综合过程 | [综述论文](templates/review.md) | 参考国内综述实例和 PLOS ONE 的综述要求；系统/范围/叙述综述须区分 |

未指定期刊时先按内容选择预设；需要直接投稿、篇幅压缩或排版时再确认目标期刊。理论研究可沿中文研究模板映射，将方法中的关键算法替换为定义、定理与证明，将结果替换为理论结论及必要验证；不强制理论论文做不适用的统计实验。

学位论文与期刊论文共用同一套内容模块，但**交付顺序不同**：学位论文按学校模板组织（通常为封面 → 声明 → 摘要 → 目录 → 正文 → 参考文献 → 附录 → 致谢 → 原创性声明），期刊稿件按刊物顺序组织。同一份研究写两种交付物时，结论、数据与边界必须一致，不得为满足不同字数或体例而改变判断；结构与措辞则分别适配。

### 标准写作模块

以下是内部内容模块，不要求正式投稿保留编号和同名标题。各模板提供这些模块的写法；可按期刊合并、重排或放到投稿系统，但不得丢失对应信息。英文模板与学位论文模板保留同一套编号，章节名按语言或学位论文惯例调整，语义一一对应。

0. 标题、作者与稿件信息
1. 摘要与关键词
2. 引言与研究问题
3. 相关工作与贡献定位
4. 研究方法与可复现信息
5. 结果与证据
6. 讨论、局限与适用边界
7. 结论
8. 数据、代码与材料可用性
9. 伦理、作者贡献、利益冲突与资助
10. 参考文献
11. 附录与补充材料

例如相关工作可融入引言，结论可融入讨论；资助或利益冲突可能只在提交系统填写。重排时保留内部映射，并按期刊要求生成正文、标题页、补充材料与提交字段，不把内部核对清单投进正文。

## 三、各部分写作要求

### 0. 标题、作者与稿件信息

- **目的**：准确表达核心研究内容，并建立可核实的稿件身份。
- **必须内容**：研究对象与核心方法/发现；确认后的作者、单位、通讯信息；内部版本、目标期刊和文章类型。匿名评审按要求单独存放身份信息。
- **表达**：标题具体但不夸大；作者名、单位、ORCID等不得推测。草稿信息不一定属于投稿正文。
- **学位论文**：题目字数按学校规定控制（如清华本科≤25 个汉字、北大研究生一般≤20 字）；封面字段、字体字号与信息排列按当届模板，不增删字段。送匿名评审的版本去除姓名、致谢与文件属性中的作者信息。
- **检查**：标题与实际证据范围一致，所有作者核实信息，匿名稿正文和文件元数据不泄露身份。
- **禁忌**：“革命性突破”无证据；编造作者/单位；未确认却标全体作者同意投稿。

### 1. 摘要与关键词

- **目的**：使读者不读全文也能理解问题、方法、主要结果和贡献边界。
- **必须内容**：研究缺口、目的/问题、方法概要、最重要结果和结论；定量研究给关键对照，理论研究给核心命题及适用假设。关键词按期刊要求提供。
- **表达**：摘要为完整短论证，不是背景加目录；按期刊选择结构化或非结构化摘要。英文摘要与中文摘要研究范围及数字一致，不逐字机械翻译。
- **学位论文**：摘要字数与是否单设一页按学校规定（如清华研究生 800~1000 字且限一页、北大研究生 3000 字以内）；本科以能独立说明问题、方法、结果、结论为准，学校未规定时不套用期刊 300 词限制。关键词常见 3~5 个、分号分隔，以模板为准。
- **检查**：每句核心主张可回到正文验证，字数、缩写及引文规则符合目标期刊。
- **禁忌**：只有“效果良好”；摘要中出现正文没有的数据；通用地强制三句或所有期刊同一字数。

### 2. 引言与研究问题

- **目的**：说明研究为何必要，以及本文将解决哪个具体缺口。
- **必须内容**：必要背景、已有知识、尚未解决的问题、为何重要、研究问题/假说、本文响应方式和贡献概览。
- **表达**：从必要背景收束到明确问题；区分文献已证实的局限和作者提出的假说。结果预览简短，不重复摘要全部数字。
- **检查**：读者能指出缺口、重要性、本文任务；每项贡献在后文有证据模块。
- **禁忌**：行业发展史占多数；宣称无人研究而无检索；把工程需求当作学术创新。

### 3. 相关工作与贡献定位

- **目的**：公平定位与已有研究的区别，建立可评审的贡献边界。
- **必须内容**：最相关的原始研究、近期进展与必要的经典工作；按问题/机制分类比较方法、数据、假设与限制；逐项说明本文继承和新增内容。
- **表达**：用比较与综合而非逐篇摘要；国内外相关研究均按相关性检索，不用机械配额或引用数量证明完整性。目标期刊特定要求另外核对。
- **检查**：被比较工作真实、条件明确，未遗漏会改变原创性判断的工作，原创与引用标识清楚。
- **禁忌**：堆文献不比较；贬低基线；只引用支持观点的来源；“首次”未经验证。

### 4. 研究方法与可复现信息

- **目的**：让合格研究者理解、复核方法，并判断它能支持哪些推断。
- **必须内容**：设计、对象/材料、来源与选择、流程、变量、参数、环境、预处理、排除和评价方法；新方法解释机制。理论研究给定义、假设、命题与证明；综述给数据库、日期、检索式、筛选和综合方法。
- **表达**：按逻辑/执行依赖组织，不按开发日记；公式定义每个符号和单位，伪代码对应正文，现有协议可引用但关键差异必须展开。
- **检查**：核心结果可复核，控制/基线公平，统计方法符合设计，事前与探索分开，依赖文献不导致无法理解本文。
- **禁忌**：只说采用某工具；隐藏排除规则或失败计分；缺失记录事后伪装为预设；只有定理无证明。

### 5. 结果与证据

- **目的**：按研究问题的顺序呈现足以检验主张的结果。
- **必须内容**：主结果、基线/对照、样本和分母、效应/差异、适当的不确定性、关键负结果；适用时给消融、敏感性、鲁棒性、典型例子和失败例；综述呈现纳入流程及文献合成，理论论文呈现证明结论与条件。
- **表达**：每段“问题—证据—局部回答”；图表自解释且与正文互补。案例给稳定ID、条件、来源、实际表现及对应结论，说明选取方法。
- **检查**：数字可复算、图文一致、指标未事后偷换；统计与实际意义分开，案例不能代替整体结论。
- **禁忌**：只展示赢家；挑最优一次运行；数据不足补造区间；无检验使用“统计显著”。

### 6. 讨论、局限与适用边界

- **目的**：解释结果、回应缺口，并限定结论的强度与外推范围。
- **必须内容**：核心发现的含义、与已有工作的一致/冲突、替代解释、内部/外部有效性、测量与样本限制、失败条件及未来验证。
- **表达**：先回答研究问题，再分析意义和局限；讨论机制时标明哪些已验证、哪些仅推测，不引入无依据的新结果。
- **检查**：每个重要局限说明会影响哪项结论；外推范围不超出样本、理论假设或检索范围。
- **禁忌**：重抄结果表；只有“未来扩大样本”；把未观察到风险写成无风险。

### 7. 结论

- **目的**：简明收束本文回答了什么，以及其学术贡献。
- **必须内容**：明确回答、最关键的支持证据、贡献与必要边界；定量结论给决定性的对照数据，理论结论给成立条件，综述给合成发现而非泛泛前景。
- **表达**：短而可独立理解；如期刊不设结论节，映射到讨论末段，不为保留模板另加标题。
- **学位论文**：通常独立成章，含"主要工作与结论 + 不足 + 展望"；展望不得写成已完成的工作，贡献表述与正文证据逐条对应。
- **检查**：结论与摘要、结果和讨论一致；没有新实验、新引用事实或超范围建议。
- **禁忌**：只有“有重要价值”；把未来工作写成已实现；为简短删掉决定性的限制。

### 8. 数据、代码与材料可用性

- **目的**：明确读者如何获取和复核研究产物。
- **必须内容**：数据/代码/模型/协议资源位置、版本、许可证、标识和权限；限制原因、可申请渠道，不能共享的内容也如实说明。
- **表达**：用可执行获取信息，不用“将适时开放”；尚未归档标待确认并说明投稿影响。
- **检查**：链接指向正确版本且权限适当；开放承诺真实，复现所需材料覆盖主结论。
- **禁忌**：虚构仓库/DOI；受限数据宣称公开；以“联系作者”掩盖可依法说明的获取条件。

### 9. 伦理、作者贡献、利益冲突与资助

- **目的**：透明说明研究合规与参与者责任、相关利益。
- **必须内容**：适用的审批/豁免、同意和注册信息；确认的贡献与署名、利益冲突、资助及资助方角色，AI辅助使用按政策披露；不适用须有依据。
- **表达**：这是内部核对模块；按期刊要求拆为独立声明或提交系统字段。不得把某刊不允许放正文的资助信息强行写入正文。
- **学位论文**：按学校模板形成原创性声明、使用授权说明、致谢与成果清单；声明须本人签署、日期真实，评语与成绩表由教师填写。匿名评审版本按通知去除身份信息与致谢。
- **检查**：各作者确认，批号/基金号/状态可核查，稿件与系统声明一致，匿名要求满足。
- **禁忌**：模板预填“无利益冲突”或“已获批准”；代用户制造签字、注册号和伦理证据。

### 10. 参考文献

- **目的**：为论证、比较与复现提供真实来源。
- **必须内容**：正文引用的可定位原始文献及完整书目信息；依目标期刊设置顺序编码、作者年份或其他格式，记录预印本/更正等状态。
- **表达**：引用紧邻所支持的陈述；写作指南和模板参考不自动成为研究论文引用。
- **学位论文**：体例由学校模板决定，同一篇内不得混用。作者-年份制（如北大经院本科）中文在前、英文在后，各按姓氏音序，只列正文引用过的；顺序编码制按首次引用排序。不把"教材/官方文档"与"期刊论文"混排冒充文献量。
- **检查**：正文与文末双向对应，DOI/链接真实且内容支持引用，版本与期刊格式正确。
- **禁忌**：凭记忆编引文；抄错引用；引用与陈述无关；为充数引用未使用资料。

### 11. 附录与补充材料

- **目的**：承接复核所需细节，同时保持正文论证清晰。
- **必须内容**：适用的完整证明、扩展结果、协议/检索式、样本与代码说明、补充图表及权限，明确编号与正文对应关系。
- **表达**：按期刊要求独立提交，正文保留决定性证据与关键局限，补充材料有可读标题和索引。
- **学位论文**：附录常承接问卷、访谈提纲、核心代码、完整表格与推导；部分学校另设图表清单与符号说明，置于目录之后、正文之前，按模板要求生成。
- **检查**：文件齐全、版本一致、引用正确，审核者能找到关键细节；图像处理和隐私符合规范。
- **禁忌**：将不利结果全部藏附录；只有无法打开的链接；补充材料与正文矛盾。

## 四、交付前检查

- [ ] 文章类型、目标读者与预设一致；正式投稿前已复查目标期刊最新指南。
- [ ] 标题、摘要、问题、贡献、方法、结果、讨论和结论形成可追溯论证。
- [ ] 原创性主张有公平的国内外文献比较，不将项目实现直接等同创新。
- [ ] 所有数字/推导/文献真实可核查，摘要、正文、图表及例子一致。
- [ ] 研究设计、统计与不确定性匹配，负结果、探索和局限未隐去。
- [ ] 典型例子解释关键贡献且注明来源/代表性，未替代统计或证明。
- [ ] 数据、代码、环境、协议、证明或文献选择过程足以复核；权限和限制明确。
- [ ] 作者、伦理、注册、利益冲突、资助与AI披露均经确认，未知项未伪造。
- [ ] 模块已映射到目标期刊正文/声明/提交系统；字数、引用、图表和匿名要求已检查。
- [ ] 占位符与虚构格式示例已移除或替换；未完成关键研究/审批时未称可直接投稿。
- [ ] 学位论文：当届模板、院系规定与培养方案已核对版本；字数、章节顺序、字体字号、行距、题注与引用体例逐项符合模板。
- [ ] 学位论文：原创性声明、使用授权、AI 使用披露已按学校要求签署，日期与签名真实，未代填教师评语或成绩。
- [ ] 学位论文：核对查重、答辩、终稿提交等节点时间，送审版/答辩版/终稿版差异留痕，提交格式与文件名符合通知。

### 官方依据与示例来源

以下核查于 2026-10-31，仅用于写作预设；不保证覆盖所有栏目最新通知。

- [《软件学报》投稿指南](https://www.jos.org.cn/jos/site/menu/20210909102616001)：原创性、明确论证、国内外相关工作比较与稿件写作要求。页面存在历史FAQ，实际提交细节需重新核对。
- [PLOS ONE Submission Guidelines](https://journals.plos.org/plosone/s/submission-guidelines)：稿件结构、摘要、复现、统计、声明与特定研究类型规范；不是所有国际期刊的统一要求。
- [arXiv Submission Overview](https://info.arxiv.org/help/submit/index.html)：预印本提交、源文件、元信息、许可、分类与版本更新要求。arXiv 是研究存储平台而非期刊，收录或审核不等于同行评审、论文录用或结论正确。
- [Attention Is All You Need（arXiv:1706.03762v7）](https://arxiv.org/abs/1706.03762v7)：英文方法研究的真实写作参照；引用应明确版本并核对出版记录，不能将预印本和正式发表版本算作两项独立研究。预印本不机械套用 PLOS ONE 的篇幅、结构或声明位置，后续投稿另核对目标期刊预印本政策。
- [Mensh 与 Kording：Ten simple rules for structuring papers](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005619)：PLOS Computational Biology 的 Editorial，供主线与段落逻辑参考，不作为原创实证研究的设计或验证模板。
