# The CL author’s guide to getting through code review

The pages in this section contain best practices for developers going through
code review. These guidelines should help you get through reviews faster and
with higher-quality results. You don’t have to read them all, but they are
intended to apply to every Google developer, and many people have found it
helpful to read the whole set.

- [Writing Good CL Descriptions](/eng-practices/review/developer/cl-descriptions.html)
- [Small CLs](/eng-practices/review/developer/small-cls.html)
- [How to Handle Reviewer Comments](/eng-practices/review/developer/handling-comments.html)

See also [How to Do a Code Review](/eng-practices/review/reviewer/), which gives detailed
guidance for code reviewers.
