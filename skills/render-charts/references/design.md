# 视觉规范

目标不是「炫」，而是**在文档里读得准、印出来也清楚**：单一强调色系、极少的装饰、所有文字有明确层级。改样式请改 `src/theme.mjs` 与 `assets/page.css`，不要在配置里逐图调色。

## 1. 色板

三套分类色板，按 `palette` 切换，默认 **`frost`**：浅彩冷调，蓝、青、绿为主，白底上轻但不飘。`editorial` 是低饱和印刷风，`vivid` 是最早的高饱和方案。10 个色位按系列顺序取用；同一系列在同一文档里尽量用同一个色位。

| 2 | `#5CC4B4` 薄荷 | `#7FDCCD` | |

**其它两套（备选）**

| 方案 | 气质 | 浅色首三位 |
| --- | --- | --- |
| `editorial` | 低饱和、印刷感 | `#3D5A80` `#B65A3C` `#2F7D6F` |
| `vivid` | 高饱和、投屏感 | `#2563EB` `#0D9488` `#F59E0B` |

切换方式：配置里写 `palette: editorial`，或命令行 `--palette vivid`。三套共用同一组墨色与色阶（色阶是冷调，见下）。

语义色单独定义，不跟随色板：负向 `#A33A2E`（深色主题 `#E08F80`）、瀑布合计用正文墨色。不要把分类色板里的某一位当作「负值色」。

墨色层级（浅色）：正文 `#0F172A`、次级 `#5B667A`、弱 `#8A94A6`、网格 `#E9EDF4`、零线 `#D6DCE6`、注释 `#7C8798`。
深色对应 `#E9EEF7` / `#A3AFC2` / `#7C8798` / `#1F2A3D` / `#3A4A66` / `#93A1B7`。

热力图与数据条用 7 档顺序色阶（浅色 `#F4F7FD → #4A7CC2`；深色 `#1B2534 → #A9CDEA`）。
表格的条件格式用 7 档发散色阶（`#B4534B → #F3F3F1 → #5C90D5`），**以 0 为中心**：正负数据不能按 min–max 铺满色阶。

## 2. 字体与字号

- 字族：`Inter, "SF Pro Text", -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei"`。
- 数字一律 `tabular-nums`（表格 CSS 已设；图表由 ECharts 文本渲染）。
- 字号：标题 16.5 / 600，副标题 12，轴标签 11，图例 12，数值标签 10.5，注释 10.5，页脚 11。
- 中文不要加粗到 700 以上；字重只用 400 / 500 / 600。
- 标题不加句号；副标题用「·」分隔维度，如「按周统计 · 2026 年 6–9 月」。

## 3. 布局

- 卡片：圆角 14，内边距 18，1px 网格色描边，无阴影。
- 图表高度默认 420；宽度在 HTML 里跟随卡片（ECharts 容器 100% 宽），静态图按 `width`。
- 网格 `containLabel: true`，四周留白：左侧有轴标题时 72，右侧双轴时 78，底部有轴标题时 28。
- 图例在绘图区内部左上角，条目间距 16，色块 9×9 圆角矩形。
- 内容顺序：标题 → 副标题 → 图 → 页脚（来源、备注）。图例属于图，不单独占一行。

## 4. 图元

| 元素 | 规格 |
| --- | --- |
| 网格线 | 只画横向，1px，网格色；`time` / `value` 轴加 60% 透明度的纵向网格 |
| 零线 | 比网格略深（`#D6DCE6`），由 ECharts 的 y 轴 0 刻度承担 |
| 轴线 / 刻度线 | 不画，只留标签 |
| 柱 | 圆角 3（只圆外端），最大宽度 46px，负值圆角朝下 |
| 折线 | 2px，圆头圆角；`smooth: 0.35` + `smoothMonotone: x`，不会过冲 |
| 数据点 | 6px 圆点，卡片色描边 1.5；点数 > 32 自动隐藏 |
| 面积 | 线色 16% 填充 |
| 参考线 | 4-4 虚线，注释色 |
| 区间带 | 注释色 7% 填充 |
| 饼/环 | 环宽约半径 24%（58%–82%），切片间 2px 卡片色描边，内角 2 |
| 数值标签 | 10.5px，次级墨色，柱顶/点上 |
| 热力图 | 单元格 2px 卡片色描边，文字按色阶明暗自动黑/白 |

## 5. 深色模式

- 页面与卡片两档深色（`#0B1220` / `#111A2B`），不是纯黑。
- 深色下分类色整体提亮；网格降到 `#1F2A3D`；提示框反相为浅底深字。
- 实现方式：同一份配置在 `build-chart.mjs` 里生成 **light / dark 两套 option**，切换时用另一套 `setOption(..., true)` 重绘，表格靠 CSS 变量换色。
- 静态 SVG/PNG 只取一套（由 `theme` 或 `--theme` 决定），打印默认浅色。

## 6. 动效

动效只服务于「从无到有」和「状态变化」，不做装饰。

| 场景 | 表现 | 参数 |
| --- | --- | --- |
| 首次渲染 | 柱从基线生长、折线绘制、饼环缩放、散点出现 | 700ms，`cubicOut` |
| 柱 / 散点错峰 | 按数据下标依次开始，避免整块同时弹入 | 18ms / 22ms 每项，封顶 260 / 300ms |
| 悬停强调 | 系列高亮、其余变淡；提示框淡入 | ECharts 默认 |
| 饼/环悬停 | 扇区沿半径向外放大 7px，标签加粗放大；小扇区露出占比 | `scaleSize: 7` |
| 图例开关 | 系列淡出/淡入，坐标轴随之调整 | 300ms 更新动画 |
| 切换深浅色 | **不重播**入场动画，直接换色 | 动画关闭 |
| 静态导出 | 不参与动画，SVG/PNG 是确定性的 | `animation: false` |

减少动态效果：`prefers-reduced-motion: reduce` 时入场动画整体关闭（`runtime.js` 在初始化前检查）。不要给表格加逐行飞入、滚动视差或循环动画。

## 7. 表格

- 表头吸顶、字号 12.5、次级墨色、左对齐文本列、右对齐数值列。
- 行分隔线 1px 网格色，悬停行底色 `--rc-chip`。
- 条件格式：`color_scale` 列按发散色阶着色（正负以 0 为中心），文字仍是正文色。
- 数据条：`bar` 列在单元格底层画一条 16% 主色透明条，长度按列最大值等比，数字浮在其上。
- 合计行：加粗、顶部 1px 分隔线、固定在表尾；只有 `totals` 里声明的列显示合计。
- 分页与搜索属于表格工具条，不进入卡片标题区。

## 8. 可访问性

- 对比度：正文与轴标签对背景 ≥ 4.5:1；图形元素 ≥ 3:1。
- 图表由 ECharts 的 `aria` 生成描述；表格是原生 `<table>`，可被读屏器逐行朗读。
- 工具栏按钮是原生 `<button>`，可用键盘 Tab 聚焦；搜索框有 `type="search"`。
- `prefers-reduced-motion` 下关闭过渡。

## 9. 不要做

- 3D、透视、阴影、发光、渐变背景。
- 每根柱子不同颜色、随机配色、彩虹色阶。
- 双轴且不标两侧单位。
- 把标题写进图片再在图注里重复一遍。
- 在柱状图上截断基线（`--check` 会直接报错）。

## 10. 改样式的正确位置

| 想改 | 改哪 |
| --- | --- |
| 色板、墨色、字号、柱宽/线宽/圆角 | `src/theme.mjs` |
| 动画时长、错峰步长、缓动 | `src/theme.mjs` 的 `MOTION` |
| 卡片、工具栏、表格、打印 | `assets/page.css` |
| 网格留白、图例位置、标注样式 | `src/build-chart.mjs` |
| 某个图的特殊情况 | 配置里的 `color` / `format` / `annotations`，不要改代码 |

改完跑 `node bin/render-charts.mjs --gallery templates -o gallery.html` 目视核对，再跑 `node --test tests/`。
