# 实验报告模板

复制本模板即可动笔，配合 [../README.md](../README.md) 使用：先读整体要求，再取模板，最后按 README 的逐节要求与交付检查核对。

三部分：空白模板 → 填写示例（示意粒度，示例值均为虚构）→ 真实示例（可核查链接，没有就写"暂无"，不要编造）。

## 一、空白模板

```markdown

- 方案与基线版本 / 数据快照：〈可追溯标识〉
- 当前状态 / 决策用途 / 访问限制：〈状态、用途与权限〉

- 判断或建议：〈结论 C1 及建议〉
```

## 二、填写示例（虚构，仅示意粒度）

```markdown
# 〈摘要长度上限 400→800 字〉实验报告

## 0. 头部信息
- 实验 ID / 报告版本：EXP-2026-11-07 / v1
- 作者 / 执行人 / 审阅人：示例作者 / 示例执行 / 待确认
- 实验起止 / 数据截止 / 报告日期：2026-11-02 至 11-06 / 2026-11-06 / 2026-11-07
- 方案与基线版本 / 数据快照：prompt v12 基线 / snapshot-20261106
- 当前状态 / 决策用途 / 访问限制：已完成 / 决定是否对长文档场景放开 / 内部

## 1. 结论摘要
- 判断或建议：建议只在长文档问答场景把摘要上限放到 800 字，其余场景保持 400。
- 关键证据：长文档子集准确率 30/58（51.7%）→ 38/58（65.5%），+8 条 / +13.8pp；端到端均值 +0.4s、P90 +1.7s（R1、R2）。
- 边界与下一步：收益集中在需要多次引用的长文档题，短问答无变化；先灰度该场景。
- 更多结论列表：C2 短问答子集 24/59 → 24/59，无差异（R3）。

## 2. 问题、假说与决策规则
- 假说 H1：摘要截断到 400 字会丢失跨段信息，导致二次检索，放宽到 800 字可减少往返并提升准确率。
- 预设（执行前记录）：主指标为 rubric 全中率；护栏为端到端 P90 与单次请求字符数。
- 决策规则：准确率提升 ≥ 5pp 且 P90 恶化 ≤ 10% 才进入灰度；未预注册的分析标注为探索。

## 3. 实验设计与数据获取
- 设计：同一批 120 条 query 分别跑两种配置（配对设计），单变量为摘要上限。
- 控制：同模型、同 temperature、同检索后端与并发设置。
- 样本与统计单位：120 条 query，按场景分长文档 60、短问答 60；统计单位为 query。
- 数据方式：离线批量跑测，轨迹落表；无线上分流，不做 SRM。

## 4. 数据处理与分析方法
- 处理：剔除 3 条无标注结果的 query，分析集 117 条（长文档 58、短问答 59）。
- 指标：准确率 = rubric 全部要点命中；分母为各子集分析集条数。
- 推断：配对方向比较；样本量不足以支持显著性检验，未报告 p 值。

## 5. 结果与效应
| 结果 ID | 指标与口径 | 基线 | 实验 | 绝对差 | 相对变化 | 样本/分母 | 不确定性与方法 | 来源 |
|---|---|---|---|---|---|---|---|---|
| R1 | 长文档子集准确率 | 30/58（51.7%） | 38/58（65.5%） | +8 条 / +13.8pp | +26.7% | 58 条 query | 未做显著性检验，方向一致 | E1 |
| R2 | 端到端均值 / P90（长文档） | 18.2s / 31.4s | 18.6s / 33.1s | +0.4s / +1.7s | +2.2% / +5.4% | 58 条 query | 均值受长尾影响，看 P90 | E1 |
| R3 | 短问答子集准确率 | 24/59（40.7%） | 24/59（40.7%） | 0 条 | 0% | 59 条 query | — | E2 |

## 6. 典型例子、反例与边界检查
| 例子 ID | 支持/限制的结论 | 输入与条件 | 证据与实际结果 | 来源与位置 | 代表性/选取方式 | 判定依据 |
|---|---|---|---|---|---|---|
| K1 | 支持 C1 | 长文档题：从 60 页规范定位两条冲突条款 | 400 字时漏第 2 条款；800 字时两条都命中 | E1 / 样本 q-0831 | 随机抽 10 条长文档题中的一条 | rubric 全中 |
| K2 | 限制 C1 | 长文档题：答案集中在首页 | 两种配置均正确，800 字未带来额外收益 | E1 / 样本 q-0902 | 同上 | rubric 全中 |
| X1 | 反例 | 长文档题：正文含表格 | 800 字时截断位置切在表格中，准确率反而下降 | E1 / 样本 q-0877 | 主动检索含表格样本 | rubric 缺要点 |

反例检查：在 58 条长文档样本中检索「截断切在表格/代码块」的情况，发现 2 条，其中 1 条准确率下降；未覆盖其他文档类型。

## 7. 有效性、局限与归因
- 内部有效性：单变量配对，配置一致；风险在于两配置共用同一检索快照，排序差异未隔离。
- 外部有效性：只在离线题集验证，真实用户长文档分布未知。
- 替代解释：提升也可能来自更长的上下文降低了重试，而非摘要本身；未做拆分实验。
- 机制：已确认的直接机制是减少二次检索，其余为推测。

## 8. 决定与后续行动
| 行动 | 依据 | 负责人 | 截止/触发条件 | 验收指标 | 风险/回滚或停止条件 |
|---|---|---|---|---|---|
| 长文档场景灰度 800 字 | C1、R1 | 待确认 | 待确认 | 线上准确率不低于基线 | 准确率下降即回退 400 字 |
| 补做表格/代码块切分保护 | X1 | 待确认 | 待确认 | 表格样本准确率不低于基线 | 未通过则不放开该子类 |

## 9. 复现资料与附录
- 数据：E1 评测集 v3（120 条）、E2 同集重跑；分析集 117 条清单
- 代码与配置：prompt v12 / v13 diff、跑测脚本（占位符代替凭据）
- 完整结果：逐题得分表、轨迹索引
```
